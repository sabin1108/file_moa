# 지난 시안 보관 안내

2026-10-25. 최종 승인 화면과 현재 UI 계약을 찾기 쉽게 만들기 위해 지난 시안 이미지·중간 검토·계획 자료 500개(17,515,390 bytes)를 활성 문서 폴더에서 분리했다. 영구 삭제하지 않았으며 디스크 공간을 비우는 작업은 아니다.

- 현재 자료: [최종 시안 목록](README.md), `final/`의 화면 캡처 72개와 관찰·소스 해시 기록, 팔레트, UI·피드백 계약.
- 과거 자료: 프로젝트 내부 `.omx/archive/prototype-20261025/prototype/`.
- 이동 목록: `.omx/archive/prototype-20261025/manifest.json`. 원래 상대 경로·크기·SHA-256을 기록했으며 이동 후 500개 모두 해시 일치를 확인했다.
- 정리 전 주요 문서: 같은 보관함의 `documents/`에 README, DESIGN, AGENTS, roadmap, screen-inventory 사본을 남겼다.

보관함은 Git에서 제외되는 **이 컴퓨터의 로컬 자료**다. 다른 컴퓨터로 프로젝트를 옮길 때 과거 시안까지 필요하면 이 폴더를 별도로 복사해야 한다. 복원이 필요하면 manifest의 `relative`에 해당하는 파일을 보관함에서 확인하고 `source` 위치에 복사한다. 같은 경로에 새 파일이 있으면 덮어쓰지 말고 내용을 비교한다.

제품 소스 90개는 정리 전후 SHA-256이 같다. 초기 요구사항 스냅샷, 제품 명세, 감사 기록, 개인 원본 자료는 이 정리의 이동 대상이 아니다. 새 최종 캡처는 production 빌드 기준이며 현재 화면에 실제 저장·AI 기능이 구현됐다는 의미는 아니다.
