
| 1   | 앱 시작 시간(TTI) 최적화                                                                                                                                                      |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|     | - 앱 시작 시 실행되는 초기 작업량을 최소화하세요.<br>- Expo Router를 사용한다면, 컴포넌트가 필요할 때만 로드되도록 비동기 라우트(Async Routes) 를 활성화하세요.<br>- Expo Atlas를 사용하여 앱 번들을 분석하고 불필요하거나 무거운 패키지를 제거하세요.     |
| 2   | 불필요한 리렌더링 방지                                                                                                                                                          |
|     | - React Native DevTools의 프로파일러를 사용하여 리렌더링이 발생하는 이유를 파악하세요.<br>- React 컴파일러를 활성화하여 불필요한 useMemo나 useCallback 등을 자동으로 제거하고 최적화를 진행하세요.                                  |
| 3   | 애니메이션을 JavaScript 스레드에서 분리                                                                                                                                            |
|     | - 목표는 항상 60fps입니다.<br>- 성능 모니터로 UI 및 JavaScript 스레드의 상태를 확인하세요.<br>- 무거운 연산으로 JavaScript 스레드를 막지 마세요. 큰 연산은 React Transition API를 사용해 처리하는 것을 고려하세요.                  |
| 4   | 최적화된 리스트 컴포넌트 사용                                                                                                                                                      |
|     | - 기본 FlatList 대신 성능이 더 뛰어난 FlashList 또는 LegendList를 사용하세요.<br>- 목록 렌더링 함수에 많은 연산이 들어가지 않도록 데이터를 사전 처리하세요.<br>- 목록 업데이트 시 불변성(immutable) 업데이트를 사용하여 리렌더링을 효율적으로 관리하세요. |
| 5   | React Context 사용에 주의                                                                                                                                                  |
|     | - Context를 앱 전체의 거대 상태 관리 도구로 사용하지 말고 선택적으로 사용하세요.<br>- 필요하다면 Jotai나 Zustand와 같이 원자적 상태(atomic state) 개념을 가진 효율적인 상태 관리 라이브러리를 사용하세요                                  |
| 6   | 메모리 누수(Memory Leak) 정리                                                                                                                                                |
|     | - useEffect의 정리(cleanup) 함수를 항상 사용하여 이벤트 리스너, 타이머(setInterval), 웹소켓 연결 등을 해제하세요.<br>- 앱이 느려지거나 충돌하는 것을 방지하기 위해 메모리 누수를 정기적으로 프로파일링하세요.                                |
| 7   | 추측하지 말고 측정하기                                                                                                                                                          |
|     | - 최적화 전에 항상 프로파일링부터 시작하세요.<br>- React Native 문서의 프로파일링 가이드를 참고하세요.<br>- Flashlight와 같은 도구로 성능 점수를 측정하거나, Sentry의 트레이싱 기능을 사용해 프론트엔드와 백엔드 전체의 병목 현상을 파악하세요.            |
