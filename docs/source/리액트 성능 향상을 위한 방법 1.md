**1**불필요한 리렌더링을 막기 위해 **React.memo**를 사용하세요.

**2**코드를 분할하기 위해 **React.lazy**를 활용하세요.

**3**가능한 경우 상태(state)를 **로컬로 유지**하세요.

**4**목록(list)에서 **keys**를 사용하되, 반드시 **고유**하게 만드세요.

**5**JSX에서 **인라인 함수(inline functions)** 사용을 피하세요.

**6**입력 핸들러에 **디바운스(debounce)** 를 적용하세요.

**7**상태 업데이트를 **일괄 처리(batch)** 하세요.

**8**비용이 많이 드는 작업에는 **useCallback**과 **useMemo**를 선호하세요.

**9**컴포넌트뿐만 아니라 **이미지**도 레이지 로드(lazy load)하세요.

**10**클래스 컴포넌트에는 **PureComponent**를 사용하세요.

**11****함수형 컴포넌트**를 고수하세요.

**12**Context를 사용하여 **Prop Drilling**을 건너뛰세요(단, 현명하게 사용하세요).

**13****React DevTools**를 사용하여 프로파일링하세요.

**14**무거운 **서드파티 라이브러리** 사용을 피하세요.

**15**CSS와 JS **번들 크기**를 최소화하세요.

**16****CDN**을 통해 애셋을 제공하세요.

**17**중요한 데이터와 애셋을 **미리 로드(preload)** 하세요.

**18****오류를 우아하게 처리**하세요(빈 화면 방지).

**19**가능하다면 **API 호출을 캐시**하세요.

**20**마지막으로, 항상 **최신 React 버전으로 업데이트**하세요.
