# 연결 위치·확장자 판별 변경 성능 기록

2026-10-31. 기존 경로 회귀 관찰이며 최적화 성과 측정이 아니다. 이전 production 빌드와 최종 수정 빌드를 비교했다. Windows, Node 24.22.1, Chrome 156.0.8078.79, localhost:3010, 1440×900 및 390×900, CPU/네트워크 제한 없음, HTTP 캐시 비활성. 각 경로 3회, 전후 각각 36표본이다. 데스크톱/좁은 폭은 별도 브라우저로 병렬 실행했고 최종 측정 중 렌더/브라우저 검증도 실행되어 CPU 경합을 배제할 수 없다. LCP 차이를 코드만의 영향으로 단정하지 않는다.

6개 대표 경로의 초기 진입을 측정했다. 파일 연결 전 상태이며 연결 후 생성 작업의 지연이나 사용자 체감/실사용 INP를 대표하지 않는다. 로그인·채팅·시안 경로의 로딩 측정은 실제 인증/AI 구현 증거가 아니다. LCP/CLS는 PerformanceObserver, heap은 CDP JSHeapUsedSize, 1.2초 관찰이며 Lighthouse/TBT/field INP/서버 부하/총 프로세스 메모리는 미측정이다.
