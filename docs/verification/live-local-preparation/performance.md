# 로컬 준비 기능의 성능 관측

동일 로컬 production 서버·Chrome·무제한 네트워크, 새 탭/공유 HTTP 캐시. 전후 각각 9경로×2폭×3회=54표본이다. files는 비인증 상태라 /login으로 이동한다. 로그인 제출·인증된 정식 채팅/파일/설정 성능이나 물리 디스크 성능을 대표하지 않는다. LCP는 n=3 중앙값, CLS는 최대, 전송은 문서+하위 자원 중앙값이다. 캐시/실행순서 잡음이 있어 작은 차이를 개선율/회귀로 단정하지 않는다.
