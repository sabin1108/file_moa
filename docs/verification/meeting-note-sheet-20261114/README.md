# 회의록 종이 크기와 지면 조정

2026-11-14 사용자 피드백: 회의록이 다른 화면에 비해 작고 디자인이 단순하므로 크기와 표현을 맞춘다.

## 변경

`ProductScenes.tsx`의 기존 회의록에 파일명 머리 부분·요약·논의한 내용·다음 할 일·예시 안내의 구분을 준다. `onboarding.module.css`는 최대 너비560→1000px, 본문20px와 두 열의 내용을 사용하며 휴대폰은334px/본문16px의 한 열로 표시한다. 기존 자료 예시의 색과8px 모서리를 맞췄다. 실제 자료로 오해하지 않게 예시 안내를 유지했다.

`onboarding-motion.module.css`는 종이를 화면 가운데 기준으로 꺼내고 확대한다. 중간 크기는65%, 끝은100%다. 처음에는 아래 부분을 폴더 안에 가려 폴더 아래로 새어 나오지 않게 한다. 새 이미지·의존성·사용자 파일 접근은 없다.

## 검증

- 관련 소개 테스트7개와 타입·린트·production 빌드 통과. 기능 안내 변경을 함께 포함한 전체156파일1422테스트·경계·구조 검사도 통과했다. 회의록 단독 배포와 계정 안내의 미배포 상태는 구분한다.
- 로컬 production 서버에서1440×900,1440×720,768×1024,390×844,390×700의 시작/폴더/꺼내기/확대20상태를 확인했다. 최종 종이 전체가 헤더 아래 화면 안에 들어오고 가로 넘침이 없다. reduced-motion과 체험 소개 경로도 확인했다. 최종 화면과 중간 꺼내기를 직접 검토했다.
- 데스크톱 최종1000px, 중간650px.390×700의 최종334px/세로127.1~640.9px로 전체가 보인다. 종이 표시 수정은 운영 DB 변경과 독립적이다.
- 근거는 `.taste-skill/guide-paper-*`와 최신 인수인계에 보관한다. 같은 이름의 과거 꺼내기 장면 검증과 구분해 현재 작업의 별도 경로로 저장한다.

실제 휴대폰 기기와 필드 성능은 측정하지 않았다. 공개 소개 화면의 표시 변경으로 계정/인증/파일 처리 정책을 바꾸지 않는다.
