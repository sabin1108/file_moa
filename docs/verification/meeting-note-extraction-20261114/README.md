# 폴더에서 회의록 한 장 꺼내기

2026-11-14. 기준 커밋 `f03436e`. 사용자는 슬로건 애니메이션의 낮은 가시성을 지적하며 삭제를 제안한 뒤, **폴더에서 회의록이 나오는 형태**로 바꾸자고 정정했다. 최신 지시를 적용했다.

## 변경과 확인 순서

1. `OnboardingPage.tsx`는 기존 `FolderScene`을 호출한다. `ProductScenes.tsx`의 이 장면은 세 카드와 슬로건 대신 회의록 한 장을 가진다. 기존 예시 문서의 제목·본문을 재사용하며 예시 회의록임을 표시한다.
2. `ScrollStories.tsx`에서 이 장면만 쓰던 `HeroWorkspace`를 삭제했다. 사용하지 않는 카드 모으기·작업 화면 펼치기 CSS도 삭제했다. 아래 자료 찾기·정리·기록 설명과 시작 경로는 유지한다.
3. 같은 스크롤 타임라인에서 서재 → 폴더 → 회의록 꺼내기 → 확대를 보여 준다. 문서는 앞면 뒤에서 출발하고 위로 나온 다음 앞 레이어로 이동한다. 꺼낸 뒤에는 폴더를 숨겨 회의록을 가리지 않는다.
4. 기존 공통 효과는 높이820px 이상에서만 동작했다. 첫 장면만 높이640px 이상으로 분리하고 고정 영역의 최소 높이를 해제했다. 아래 효과의 조건은 유지했다. 휴대폰은 꺼내는 높이를 줄인다. 동작 줄이기·타임라인 미지원·더 작은 화면에서는 정적 서재와 아래 설명이 남는다.

표시용 코드 변경이며 실제 파일 열기·로컬 쓰기·AI 전송을 추가하지 않았다. 새 패키지·생성 그림도 없다. 공개와 체험 소개는 같은 구현을 사용한다.
