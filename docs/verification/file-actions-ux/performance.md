## 작업 화면 관측

[실제 복사](final/copy/checks.json)의4×16MiB 실행→완료는 **1341.77ms(n=1)**였다. 실제 OPFS 쓰기와 hash 검증을 포함하지만 CDP 입력·권한 fixture·journal·polling도 포함하므로 순수 I/O 처리량이나 실사용 지연이 아니다.

[계획 생성](final/plan/checks.json)은390×1000px에서 100파일 중앙값 67.88ms [63.49–75.31], n=3; 1000파일 중앙값 638.96ms [546.63–665.3], n=3였다. 목록 열거+계획 계산+트리 렌더+CDP polling 합성 관측이다. UI 변경 중 같은 세션에서 측정했고 마지막 완료 화면 접힘 변경 이전 표본이다. 검사 스크립트의 hash/Worker 시간도 남겼으나 다른 독립 기능 검사와 병렬 실행했으므로 비교 성능 결과로 채택하지 않는다.

팝업 휠은 위치별 실제 CDP wheel로 배경 고정과 목록/팝업 이동을 확인했다. 이를 입력 지연 또는 스크롤 FPS 수치로 바꾸지 않는다. 완료 확인의 목적지 이동은 기능 검증이며 별도 충분한 시간 표본이 없다.
