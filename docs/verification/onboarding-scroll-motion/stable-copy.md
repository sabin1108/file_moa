# 고정된 종이와 제자리 문구 교체 — 2026-11-11

사용자가 반복 종이 교대를 거절하고 글자만 간단하게 바꾸는 방향을 승인했다. 반환/추출/대기 상태와 animationend 전환 로직을 삭제했다. 처음 한 번의 종이 등장 후에는 같은 종이와 같은 SearchScene을 유지한다. 검색·원문·답변 예시를 한 지면에 담고 기능 선택 때 제목/설명과 강조 테두리만 변경한다. 글자 효과와 지면 교체는 없다.

고정된 제목/본문 영역으로 문구 길이가 달라도 읽기 면을 유지한다. 모바일은 중복 결과 문장/경로를 줄이고 원문과 답변을 같은 지면에 남겼다. live 영역은 문구 변경을 알리고 JavaScript 없는 경우 noscript 설명을 제공한다. 움직임 감소에서는 처음 등장도 생략한다. 추가 패키지 없음.

검증: 관련13개 테스트, 타입·린트·production 빌드 통과. 실제ego1440/390/320에서 세 선택9상태의 동일 종이/동일 지면 DOM, 첫 애니메이션 시작 시각 불변, 내용 가림/가로 넘침 없음을 검사했다. 선택 사이 종이 높이·위치가 완전히 같음을 별도 단언했다. 스크롤0/1/2/0 복귀와 reduce 상태의 즉시 선택·종이1개·애니메이션0을 확인했다. 결과 `.omx/verification/onboarding-static-20261111/`.

첫 화면과 정리 예시는 이번 범위 밖이다. 물리 터치·Safari/Firefox는 미검증이며 미커밋·미배포다.
