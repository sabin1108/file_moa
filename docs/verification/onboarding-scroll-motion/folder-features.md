# 폴더에서 나오는 설명 종이 — 2026-11-11

사용자가 일반 흐름 비교안을 거절하고 폴더에서 종이가 나와 기능을 설명하는 연출을 요청했다. 검색 소개의 검색/원문/답변 설명을 각각 종이로 구성하고 기존 제품 예시를 재사용했다. 폴더 배경과 앞면 사이에 종이를 배치해 아래에서 올라오는 동안 앞면이 종이를 가리고, 마지막에는 내용을 가리지 않는다.

기존 일회성 IntersectionObserver는 움직이는 종이 대신 고정된 폴더 영역을 관찰한다. 진입하면 종이에 실행 속성을 붙이고 관찰을 해제한다. 준비된 화면에서는 종이가 접혀 있고 1.4초 동안 위로 나오며, 이후 읽기 위치에 멈춘다. 스크롤 시간에 재생을 묶지 않는다. JavaScript/API 미지원에서는 기본 펼침 표시, 움직임 감소에서도 변형 없이 표시한다.
