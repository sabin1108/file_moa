## 변경과 책임

- OrganizationStory의 세 제품 패널을 하나의 OrganizationScene으로 바꿨다. 파일 이름·아이콘의 DOM은 유지한다. 검토 단계에서 화살표/목적지가 나타나고 정리 단계에서 목적지가 위쪽으로, 파일이 그 아래로 이동하며 확인 표시가 생긴다.
- OrganizationDemo는 설명 위치를 IntersectionObserver로 관찰해 단계만 선택한다. CSS transition은 현재 값부터 새 위치로 이어진다. 프레임별 스크롤 진행과 마스크/전체 화면 슬라이드를 사용하지 않는다. 설명은 일반 흐름이며 관찰은 해제된다. 움직임 감소에서는 전환 시간을0으로 한다.
- 검색 기능 종이는 유지하고, 종이 등장 후 검색어 강조색·원문 경계·답변의 선명도가 순서상 이어지게 했다. 완전히 투명한 전체 화면을 교차 표시하지 않는다.
- 소개는 정리의 예시다. 원본 접근·실제 파일 변경·모델 요청을 추가하지 않았다. 목적지 검토와 확인 전 원본 보호, 복구용 보존본 설명을 유지했다.
