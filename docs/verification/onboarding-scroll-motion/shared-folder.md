# 하나의 폴더에서 한 장씩 꺼내기 — 2026-11-11

사용자는 검색·원문·자료 대화가 하나의 폴더를 공유하고 다음 기능으로 넘어갈 때 같은 폴더에서 다음 종이를 꺼내도록 요청했다.

KnowledgeExamples에 폴더 앞뒤 면은 하나만 두고 세 설명 종이를 보관했다. waiting→extract→idle→return→extract로 동작한다. 스크롤 관찰과 기능 버튼은 요청만 갱신하며 CSS animationend에서 반환 완료 후 요청한 종이를 선택한다. 진행 중 요청은 마지막 것만 유지하고 추출 완료 후 필요하면 다음 반환으로 이어간다. CSS 애니메이션은 scroll 위치에 묶이지 않는다.

표시 종이는 항상 한 장이다. 숨긴 종이는 hidden 속성으로 접근성 트리에서도 제외하며 버튼은 키보드 조작 가능하다. JavaScript 전에는 세 설명을 모두 펼친다. 움직임 감소에서는 즉시 선택하고 애니메이션을 실행하지 않는다. 관찰/설정 변경 구독은 정리한다.
