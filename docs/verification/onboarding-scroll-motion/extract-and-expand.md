# 폴더에서 뽑아 확대하는 문서 — 2026-11-11

사용자는 첫 폴더의 문구 다음에 작업 화면이 갑자기 올라오는 점을 지적하고, 검색/원문 설명도 폴더에서 문서를 뽑듯이 이어지길 요청했다.

첫 HeroWorkspace를 FolderScene 내부에 넣었다. 폴더 앞면과 같은 스태킹 문맥에서 작은 문서가 가려졌다 나오고, 폴더를 벗어난 뒤 같은 요소가 전체 작업 화면으로 확대된다.0–48%는 작은 문서,48–68%는 추출,69–94%는 확대다. 전체 화면 clip-path/불투명도 교체를 제거했다. 폴더가 먼저 사라져 다른 화면이 나타나는 흐름도 제거했다.

기능 설명 종이는34%크기에서128px 아래에 있다가,1.8초 중45% 시점에180px 위로 꺼낸 후 전체 크기로 펼친다. 검색어/원문/답변 강조 시작은1.5초로 늦췄다. 기본 펼침·움직임 감소와 기존 일회성 관찰은 유지한다.

관련 테스트13개(작업 문서가 폴더 앞면 앞에 렌더되는 구조 포함), 타입, 린트, 마지막 CSS를 포함한 production 빌드 통과.

실제ego1440/390px의16개 첫 화면 단계에서 폴더 내부 요소 유지·불투명도1·마스크없음·가로 넘침없음을 검사하고 확대/역방향 위치를 확인했다. 초기 확인에서 작은 문서 하단이 폴더 아래로 드러나 시작 위치를 추가 보정했다. 최종 검색/원문은 두 폭4조합에서 Web Animations의0/810/1800ms를 명시적으로 표본 검사해, 중간 크기가 최종의 절반 미만이고 문서 하단이 폴더 앞면보다 위에 있는지 단언했다. 이는 고정 시간 표본 검사이며 물리 스크롤 시간 측정과 구별한다. 움직임 감소에서 설명 변형없음 확인.
