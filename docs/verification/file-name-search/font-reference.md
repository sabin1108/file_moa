# Gothic A1 검토 후보 — 2026-10-29

사용자는 “Gothic A1 같은걸 추천한다고 하네, 참고해줘”라고 요청했다. 이번 단위는 추천을 검토 기준에 반영하고 기존 시스템 서체를 유지한다. 서체의 읽기 편안함이나 성능이 기존보다 낫다고 단정하지 않는다.

## 확인한 공식 자료

- Google Fonts는 Gothic A1을 한국어·라틴 문자 서체로 설명한다. [공식 설명](https://github.com/google/fonts/blob/main/ofl/gothica1/DESCRIPTION.en_us.html)
- Google Fonts 메타데이터에는 HanYang I&C Co, normal 스타일의 100~900까지 9개 정적 TTF, korean/latin 등의 subset이 기록돼 있다. 가변 폰트라고 가정하지 않는다. [공식 메타데이터](https://github.com/google/fonts/blob/main/ofl/gothica1/METADATA.pb)
- 배포 라이선스는 SIL Open Font License 1.1이다. 나중에 폰트를 함께 배포할 때 저작권 안내와 라이선스도 보존한다. [배포 라이선스 원문](https://github.com/google/fonts/blob/main/ofl/gothica1/OFL.txt)

## 적용 전에 비교할 것

이는 앞으로의 프로젝트 비교 계획이며 이번에 측정한 결과가 아니다. 현재 `styles/globals.css`의 시스템 서체와 같은 화면·문장·폭에서 비교한다.

1. 본문 16~17px, 기존 행간/읽기 폭을 유지한 긴 한국어 문장, 숫자·영문 혼합 파일명과 굵은 제목을 비교한다. 우선 본문/강조/제목에 필요한 400/500/700만 후보로 삼고 모든 굵기를 일괄 추가하지 않는다.
2. 로컬 제공을 우선 검토하고 한글 커버리지와 실제 파일 크기를 확인한다. 필요한 글자만 잘라 사용자 파일명의 드문 글자가 빠지지 않도록 fallback도 확인한다. 변환/부분집합 배포를 선택하면 라이선스 조건과 생성 과정을 함께 기록한다.
3. 실제 폰트 파일을 로드한 전후 전송량·LCP·CLS, 지연 로딩 시 글자 바뀜/줄바꿈, 390/1440/1920px를 비교한다. 현재는 폰트를 내려받거나 설치하지 않았고 크기/읽기 편안함을 측정하지 않았다.

로그인 구현 보류와 별개로 이 후보는 다음 UI 작업에서 재사용한다. 승인된 채팅 시안을 이번 검색 기능 때문에 다시 설계하지 않는다.
