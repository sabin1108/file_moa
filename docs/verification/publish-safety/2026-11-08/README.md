# GitHub 공개 전 점검

2026-11-08. 이번 누적 작업을 커밋·푸시하기 전 수행한 공개 범위 검사다. 모든 보안 취약점이 없다는 보증이나 실제 모델 품질 검증으로 해석하지 않는다.

## 공개할 자료와 제외할 자료

- 제품 소스, 테스트, 합성 TXT/MD/PDF/XLSX 자료, 공개해도 되는 검증 기록을 포함한다.
- `.env.local`, `.next`, 생성된 Prisma client, `.omx` 실행 상태·측정 복사본은 Git에서 제외한다.
- 실제 디스크 수동 관측 `manual-*.json` 5개는 로컬에 보존하고 [공개 요약](../../live-organization-completion/manual-summary.md)으로 대체했다.
- 완료되지 않은 최초 측정 초안은 제외하고, 완료된 비교의 원자료·CSV·보고서는 보존했다.
- 공개 JSON의 로컬 프로젝트 절대 경로는 `PROJECT_ROOT`로 바꿨다. 개인 사용자 홈 경로는 `%USERPROFILE%`로 바꿨다. 측정 숫자·표본·빌드 식별자는 바꾸지 않았다.
- 합성 문서의 모델 응답·사용량은 평가 근거로 유지한다. 요청 식별자는 인증 비밀이 아니며, 원본 사용자 쿠키·세션 토큰은 포함하지 않는다.

## 비밀값·개인정보 검사

현재 추적 파일과 새 공개 후보 전체를 대상으로 실제 로컬 환경의 키·비밀값 및 URL/base64 표현을 비교했다. 실제 값 일치 0개였고 일반 키·JWT·private key·인증 포함 DB URL 패턴도 검사했다. 발견된 DB URL 4개는 테스트의 localhost/fixture 값이다. 이메일 탐지는 공개 예시 발신자 `onboarding@resend.dev`만 확인됐다. 새 JSON의 실제 token/password/cookie 등 필드도 찾지 못했다.

최종 공개 JS/CSS 42개와 로컬 환경의 비밀값 10개를 정확히 대조한 결과 일치 0개다. Vercel의 비밀값 자체를 조회한 검사는 아니며 서버 전용 import·접근 경계도 별도로 확인했다.

새 이미지 209개는 9개 묶음으로 확인했고, 로그인·설정 관련 화면은 확대해서 확인했다. 계정 비밀번호·키·인증 헤더를 표시한 화면은 발견하지 못했다. 모든 이미지의 작은 글자를 OCR로 전수 판독한 검사는 아니다. 자료는 격리 브라우저와 합성 파일을 사용한 조건을 따른다.

## 공개 샘플 비용 경계 수정

OpenAI 키를 Vercel에 추가하면 공개 `/demo`까지 유료 모델이 켜지는 구조를 발견했다. 공개 배포는 샘플 AI 기본 비활성으로 바꾸고, 서버의 샘플 예약/분류 경계에서 다시 확인한다. `ENABLE_PUBLIC_SAMPLE_AI=true`로 명시한 경우에만 공개 전송을 허용한다. 로그인한 정식 AI와 로컬 개발의 기본 동작은 유지한다.

실제 production 서버에서 Vercel 환경과 합성 키를 사용해 페이지의 전송 차단을 확인했다. 생성한 테스트 샘플 쿠키로 두 Server Action을 직접 호출해도 `unavailable`로 거부됐으며, 별도의 모델 네트워크 차단기가 관측한 모델 호출 시도는 0회였다. 실제 사용자의 인증 쿠키를 추출하지 않았다.

- [분류·정리 Action 직접 호출 거부 2개](sample-action-checks.json)
- `sample-public-ai.test.ts`: 공개 기본 거부·Vercel·직접 호출·명시 허용·잘못된 설정·로컬 동작 7개.

## 검증

전체 113파일 1,088개 단위 테스트, 타입·린트·서버 경계 21개·구조 경계 25+6+3개·Prisma schema 검사·production build 통과. 최종 빌드 `rw8jPzJJbDAQWv1Jh2vIK`.

스테이징 후의 실제 Git blob도 다시 검사해 환경 비밀값과 예상하지 않은 토큰 패턴 0개를 확인했다. 테스트 원문 36개는 Git blob과 작업 파일의 바이트 일치도 확인했다. 의도적인 빈 줄을 제거하지 않고 Git 속성으로 fixture 바이트를 보존했으며, 데이터셋 5개 검사도 통과했다.

테스트용 preload의 첫 Windows 경로 표기가 해석되지 않아 서버가 시작되지 않은 시도는 경로 구분자를 정리해 재실행했다. 해당 연결 거부를 제품 오류나 모델 실패로 계산하지 않았다. 실제 유료 모델 호출은 실행하지 않았다.
