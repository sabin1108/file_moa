# Luna 고정·초대 배포와 3달러 미만 실제 검증

2026-11-16. 사용자가 이전 로컬 수정의 커밋·푸시·Vercel 적용을 승인하고, Luna 고정·총3달러 미만 유료 검증·한도 도달 전 알림·실제 데모 동작 확인을 요청했다.

## 현재 상태

- 소스59파일을 `505a54c18e23ce297a9c792ea43ae845105df375`로 커밋해 `origin/main`에 일반 푸시했다. 개인 기록 문서3개는 제외했다. 기존 검증본의 해시를 확인했고 제품 코드는 추가 변경하지 않았다.
- `DEMO_ACCESS_TOKEN`과 `AI_PROVIDER=openai`, `ENABLE_PUBLIC_SAMPLE_AI=false`를 서버 Production 비밀 설정으로 저장한 뒤 초대 코드의 첫 배포가 Ready가 됐다. [첫 배포](https://vercel.com/sabins-projects-011c6dea/web/9pR47ra7qSgEPunAU1RDozhWBDm8).
- 실제 `web-eight-rho-72.vercel.app`에서 초대 없는6경로/잘못된 초대404, 정상 초대303·HttpOnly/SameSite/Path·no-store/no-referrer, 세션/방문자 유지 등14개 HTTP 검사가 통과했다.
- 그 뒤 `ENABLE_PUBLIC_SAMPLE_AI=true`를 저장한 재배포에 Vercel 이메일 본인 확인이 필요했다. 사용자가 직접 완료한 뒤 같은 space를 넘겨받았으며 [AI 활성화 배포](https://vercel.com/sabins-projects-011c6dea/web/BmEM2WYDUcCLhZiKcd44FtXqgJmn)가 Ready가 됐다. 인증 우회나 새 푸시로 인증 단계를 피하지 않았다.
- 실제 배포 화면에서 일반/후속 대화·자료 질문·정리 생성4회와 UI28개, 활성화 뒤 접근14개가 통과했다. 추가 수정 없이 문서 결과를 커밋하며, 최종 문서 배포 상태/HEAD는 로컬 `current-status.json`/`release-receipt.json`을 따른다.

## 실제 배포 화면 검증

Ego space8의 실제 HTTPS 사이트에서 사람이 사용하는 화면 조작으로 확인했다. 합성 action을 넣거나 DB 예약을 대체하지 않았다. 샘플 자료만 선택했고 운영 DB 직접 조회/관리·개인 폴더 접근은 하지 않았다.

- 명시 시작의 기존17단계 안내와 선택0, 입력만으로 유료 호출 없음.
- 실제 일반 답변과 Enter 후속 질문의 ‘첫 번째 항목’ 맥락 유지. 반환 모델은 모두Luna.
- 키보드 파일명 검색으로 분기 영업 요약1개 선택→전송 동의→매출14500만원 답변→해당 출처 버튼으로 원문8400/6100 확인.
- 같은 파일만 선택 범위로 정리 요청→날짜 분류 없이 ‘영업 자료’ 목적지 제안→미적용 검토→명시 가상 적용→새로고침 후 전체 메시지/되돌림 상태/위치 일치→되돌림으로 이전 위치 복원.
- 로컬 매출 검색과 설정 공급자 확인, 기존17단계 다시보기, 새로고침에서 안내/유료 요청 재실행 없음.
- 390/768/1440/1920px 가로 넘침0. 초기 캡처의 닫힘 전환 중 겹친 잔상은 안정 상태를 기다려 재캡처했다. 모바일 실기기/물리IME 완료로 확대하지 않는다.

28개 체크가 모두 통과했다. 실제 유료 전송은4회뿐이며 조회/튜토리얼/적용/되돌림에서 추가 생성하지 않았다. HTTP200뿐 아니라 저장된 모델 응답/출처/가상 계획을 별도로 판정했다. 서버 action 응답에서 관측한 usage는 각각237/287/532/1070토큰이며 예산에 정산했다. 앱의 실제 예약 경유 호출 성공을 확인했지만 실서비스 로그인/계정10회 차단·데모31번째 차단·동시 경쟁/운영 DB 전체 감사를 수행한 것은 아니다. 앞선 모의 원자 예약 회귀와 구분한다.

원자료 `production-ui.json`, `ego-30.mjs`~`ego-43.mjs`, `screens/stable-*.png`. 전환 뒤 stale ref1회는 새 snapshot/안정 선택자로 복구했고 그때 유료 호출은 발생하지 않았다. 제품 실패를 숨기거나 검사 수에 합산하지 않는다.

## 비용 기록과 한계

이번에 추적한13생성(기존3+품질6+배포UI4)의 표준 토큰 가격 기준 예상액은 **$0.0011481**, 미정 예약은0이다. 입력$0.10/1M, 출력$0.50/1M 기준이며 계정 청구액과 다르다. 실제 계정 누적 청구/세금/다른 사용자 호출/크레딧은 확인하지 않았다.

새 호출 전에 최대8192입력+3200출력 상당 `$0.0024192`를 먼저 예약한다. 추적 비용+예약+새 예약이 `$2.99` 이상이면 호출을 멈추고 사용자에게 알린다. 정상 usage를 받은 뒤 정산하며 실패/사용량 미확정은 보수적인 예약을 유지하고 자동 재시도를 막는다. 이는 해당 검증 흐름의 예산 경계이며 서비스 전체나 OpenAI 계정의 자동 결제 상한/상시 알림이 아니다.

원자료는 `.omx/verification/paid-ai-deploy-20261116/{quality-results,production-ui,budget,http-gated,current-status,commit}.json`과 `quality.check.ts`/`budget.mjs`다. 독립 architect 검토는 관찰·예산의 일치와 위 미검증 경계를 확인했다. 테스트 예산3달러를 소진하기 위한 불필요한 반복 호출은 하지 않는다.

## 보존과 보안

실제 초대값은 저장소 밖 이 작업 전용 Temp 파일과 Vercel 서버 비밀에만 둔다. 입력 점검 중 아직 사용하지 않은 임시 초대값이 도구 출력에 포함된 실수가 있어 그 값을 폐기하고, 새 난수만 실제 환경에 저장했다. 배포 전 교체를 마쳤으며 원문은 문서·Git에 기록하지 않았다. API 키 원문은 읽거나 출력하지 않았다.
