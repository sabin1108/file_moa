# 온보딩 초반의 AI 기록과 원본 보호 안내

## 후속 정정 — 걱정이 먼저 보이는 구성

사용자는 긴 설명을 다 읽어야 뜻을 알 수 있는 점을 지적하고 AI 불안감 등 사용자의 걱정을 알아주는 문구로 시선을 끌도록 요청했다. 소개 안전 안내의 큰 제목을 ‘AI에게 내 자료, 맡겨도 괜찮을까?’로 바꾸고 잘못된 답·임의 파일 변경·대화 소실의 질문을 대책보다 먼저 배치했다. 각 대책은 한 문장으로 보이며 기존 상세 조건은 항목별 닫힌 네이티브 details로 펼쳐 읽는다. 데모 차이 안내는 접지 않았다. 기존 투어·파일/저장/AI 동작은 이번 정정에서 바꾸지 않았다.

Ego 공개390/768/1440/1920px에서 질문3개/제목2줄/가로넘침0/상세기본숨김 확인, 각 summary의 Enter열기·Space닫기·초점 유지 확인. 데모의 범위 안내가 펼치기 밖에 보이고 상세가 닫힌 상태임을 확인했다. `concern-layout.json`, `concern-keyboard.json`, `concerns-*.png`가 이번 근거다. 전체 기능 테스트·공식 taste 전체 판정·성능 수치는 이번 문구/표시 변경에서 실행하지 않았다. 앞선 검증은 아래에 보존한다. 기존 로컬3035가 살아 있어 최초 시작은 EADDRINUSE였고, 이번 대화에서 시작한 기존세션92079를 종료한 뒤 최신 빌드로 다시 열었다. 새 로컬3035는 사용자가 미리보기를 볼 수 있도록 유지한다. 배포·커밋·푸시·개인 폴더/운영DB/유료AI 호출은 없다.

## 변경과 읽을 순서

1. `apps/web/src/features/onboarding/OnboardingPage.tsx`: 첫 화면 다음, 자료 찾기 설명 전에 안전 안내를 배치한다. 발췌 전송 동의·출처 확인, 저장 위치와 대화 저장 설정, AI 초안/편집 본문/이전 버전, 파일 변경 전 보존·검증·복구와 별도 백업 조건을 설명한다. 공개/체험이 공유하며 체험의 개인 파일 변경·로컬 영구 저장 미연결을 구분한다. 헤더와 첫 스크롤 링크로 바로 이동한다.
2. `onboarding.module.css`: 기존 split·색·서체를 재사용하고 정의 목록 간격만 추가한다. 새 카드·그림·의존성·동적 동작은 없다.
3. `workspace-tour-steps.ts`: 첫 인사 뒤 2단계를 추가해 19단계를 공유한다. 두 단계는 현재 경로와 기록 탭을 유지하며 저장·권한·AI 전송을 실행하지 않는다. 기존 `WorkspaceTourOverlay`와 대상 선택자를 그대로 사용한다.
4. 소개·투어·데모 공통 테스트와 두 명세, `DESIGN.md`를 갱신했다.

## 문구 근거

- `AiStorageSettings.tsx`: 사용자 지정 로컬 기록 폴더, 명시적 대화 저장, 암호화되지 않는 파일.
- `RecordEditor.tsx`: AI 초안/편집 본문 구분과 저장한 이전 버전.
- `InlineDocumentEditor.tsx`: 편집 첫 저장 시 원본 사본 보존.
- `ManagedOperationView.tsx`, `RecoveryOverwriteView.tsx`: 이동·휴지통·덮어쓰기의 보존본 검사와 명시적 실행, 작업 기록과 복구 사본.
- 데모 영구 저장·개인 원본 작업 미연결은 최신 인수인계와 기존 데모 context 안내를 따른다. 로컬 사본을 기기 고장까지 보장하는 백업으로 표현하지 않는다.

읽기 전용 보조 에이전트가 근거를 조사했으며, 오래된 명세의 미구현 표현은 부모가 현재 UI 소스와 대조했다. 전체 코드 리뷰나 파일 복구 재검증은 아니다.
