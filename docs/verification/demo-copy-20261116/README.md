# 입력 예시와 데모 안내 정리

2026-11-16, 기준9c10e6f 이후 사용자 피드백을 반영했다. 별도 UI를 만들지 않고 정식/데모의 공통 작업 선택·입력·설정 표시를 재사용한다. 초대 이름은 아직 지정받지 않아 기존 주소/비밀값을 유지한다.

- `ConversationTaskControls`의 예시 펼침/버튼/반복 문장을 제거하고 작업 설명을 남겼다. 같은 모듈의 `conversationInputPlaceholder`를 정식/데모가 사용해 입력 안내 둘째 줄에 `예:`와 작업별 예시를 표시한다. 입력 예시로 초안이나 전송을 자동 실행하지 않는다.
- 데모 입력 영역에서 하루 한도·최근 완료3회 전송·초대/브라우저 집계 주의 문구를 제거했다. 최근 대화 전송의 실제 동작과 설정의 상세 안내, OpenAI 공급자 표시, 자료 질문/정리의 전송 동의는 유지한다.
- 첫 빈 대화에 ‘개인정보나 비밀번호는 입력하지 마세요. 대화는 이 탭에 임시 보관됩니다.’를 짧은 note로 표시한다. 메시지가 있으면 intro 대신 메시지를 렌더링하므로 주의를 반복하지 않는다. 별도 storage/모달/새 상태를 만들지 않았다.
- 공통 설정에 남아 있던 ‘1시간10회’를 현재 일일 정책으로 정정했다. 같은 `AI_DAILY_LIMITS`를 사용해 데모30회/정식10회와 한국 시간 자정 초기화를 표시한다. 서버 한도·초대·모델·예약·취소·복원 코드는 변경하지 않았다.
