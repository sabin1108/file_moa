# 공통 탐색·샘플 확장의 로컬 성능

최종 빌드 `P35v69WziYQC9Sgl0-w1u`, Windows/Next production/Chromium headless/로컬 loopback, CPU·네트워크 제한 없음. 성능 측정은 기능 브라우저 검사가 끝난 후 실행했다. 사용자 실환경이나 물리 디스크의 수치가 아니다.

- `performance-after.json`: guest6경로 + 샘플 대화/파일/설정,390/1440px×3회=54표본. `/files`는 인증 보호에 따라 로그인으로 이동한다. 공통 HTTP 캐시가 있으므로 JS 전송0을 초기 비용0으로 해석하지 않는다.
- `performance-cold.json`: 샘플 대화390/1440px×3회=6표본, HTTP 캐시 비활성. JS 전송이 실제 발생했는지 스크립트에서 검사했다. 모델 요청 없음.

새 전역 메뉴/설정/공통 트리와50개 추가 자료가 만드는 비용을 포함한다. 모든 정적 chunk 합계는 한 번의 방문이 다운로드하는 양과 다르다. 자원 전송은 navigation document를 제외하며 문서 전송값은 원자료에 따로 있다. 시간대와 소표본 차이가 있어 LCP 감소를 개선율로 주장하지 않는다. LCP/CLS만으로 상호작용 자연스러움을 판단하지 않았다.

공유캐시 LCP 중앙값390/1440은 대화64/68ms, 파일68/92ms, 설정52/60ms다. 메뉴/자료 창 상태·Esc/초점·reduced-motion·파일 hold 충돌은36개 동작 검사에서 별도로 확인했다. 실사용 INP·상시 메모리/장기 사용·실제 계정의 파일 규모별 처리·확대 자료의 모델 시간/비용은 이번에 측정하지 않았다. 기존 두 모델 요청의 수치는 이전 빌드의 역사적 표본이며 현재84개 분석의 수치로 재사용하지 않는다.
