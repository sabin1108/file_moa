## 수정과 근거

기존 Server Action은 JSON이 완성된 뒤에만 반환했다. 대기 중 포커스도 이전 답변에 남아 생성 과정이 화면에 보이지 않았다. 데모 전용 POST SSE를 추가하고 기존 JSON 생성에 선택적 스트림을 연결했다. 실제 output text에서 answer/summary만 보여 주며 reasoning·원시 JSON·미검증 계획은 공개하지 않는다. 완료 시 기존 근거·경로·자료 검증을 다시 통과해야 계획을 적용할 수 있다.

상단 전체 초기화 버튼과 확인 UI를 제거했다. 기본 정리 위치는 정리한 자료/정리 결과이며 준비 전에 이름을 바꿀 수 있다. 폴더는 검토한 계획을 명시 적용할 때 생성된다. 공통 변경 계획·파일 적용·복원 경로를 사용한다.

정리 채팅 입력은 controller.replyDraft에 연결하고 최초 요청 수정은 별도 초안으로 관리한다. 입력만으로 snapshot·선택·질문·동의가 바뀌지 않는다. 유효한 답변 적용 시 이전 계획과 전송 동의만 해제한다. 중단·형식·인용 검증 실패 시 실제 받은 문장은 검증 전 답변으로 저장하며 draft와 선택을 보존한다. 자동 유료 재시도는 없다.

## 성능과 범위

초기 수정 빌드 JS/CSS54파일4,578,381bytes, 직전4,573,004 대비5,377bytes 증가였다. 후속 최종 수치는 아래 운영 확인 절을 따른다. 스트림 조각은 탭 메모리에서만 갱신하고 완성/중단 시 저장한다. SSE는 증분 전송이며 ID/sequence/길이/프레임/완료 및 취소 검사를 사용한다. 합성 대기 화면은 실제 모델 응답 시간 측정이 아니다.
