## 비교 대상

- 이전 방식 복원: `-EF8-XwVvWif1lXYYzMLN`, 로컬 3035.
- 현재 방식: `69sz8moxeLbyN5dDtl0GI`, 로컬 3036.
- 수집 화면: 로컬 3037. 원래 사용자 앱 3034는 수정하지 않았다.
- 소스 해시: `.omx/settings-timing/measurement-20261108-v2/manifest.json`.
- 이전 reader는 프로필을 세션에서 얻고 현재 cache miss는 프로필 DB 조회가 추가된다. 이 실험은 전체 조회 방식 변화의 비교이며 캐시 API 하나만의 효과를 분리하지 않는다.

## 측정 조건

실제 인증·DB, 동일한 화면·계정의 로컬 production 비교다. 모든 Next Link prefetch를 측정 복사본에서 끄고 고유 query로 client navigation을 실행한다. 실제 메뉴의 Router Cache/prefetch가 있는 탐색과 다를 수 있다. 시작마다 해당 측정 서버만 재시작하고 복사본의 fetch-cache만 지운다. 브라우저 HTTP 캐시는 유지한다.

한 번의 실행에서 작업 공간 10회·계정 설정 10회 탐색을 측정한다. 첫 작업 공간, 첫 설정, 두 구간의 합, 나머지 9회 설정을 나눠 중앙값·범위를 기록한다. 작은 표본의 p95를 안정된 실사용 지표로 해석하지 않는다. 두 frame 뒤 준비 확인은 화면 반영을 관찰하는 도구이며 LCP·INP·실제 사람의 주관적 체감 측정이 아니다.

브라우저 지표는 시행 종료 후 일괄 전송하고 서버 reader의 시간과 callback 실행 여부는 별도 기록한다. 서로 다른 시계의 브라우저/서버 시간을 빼서 네트워크 시간이라고 표현하지 않는다. 후속 callback 실행은 60초 재검증의 영향을 받을 수 있다.

AI 키는 테스트 프로세스 환경에 포함하지 않는다. DB·인증 구성만 허용하고 메일 키도 합성 값이다. 쿠키는 기존 인증 과정에서만 사용하며 측정 수집기로 보내거나 파일에서 추출하지 않는다. 기록에는 계정 이름·이메일·토큰·본문을 포함하지 않는다.

## 실행 증거와 초기 실패

두 버전 Next production 빌드 통과. 숫자 지표 검증/통계 self-check 4개, 환경 격리 5개, 비로그인·Origin/nonce 차단 6개, 브라우저의 시작→서버 재시작→수집기 통신→비로그인 리다이렉트 확인을 실행했다. 이 검사는 실제 로그인 성능 수치가 아니다.

첫 사용자 시도는 제한된 실행 환경의 DB TCP 접속이 `EACCES`로 차단되어 서버 오류가 났다. 이 상태의 시간은 유효 표본에 포함하지 않는다. 권한을 갖춘 읽기 전용 SELECT 1 검사는 통과했고 측정 서버를 해당 환경으로 다시 실행했다. [실패 시도 원자료](measurement-20261108-v2/attempt-sandbox-blocked.json)를 보존했다. 처음 환경 허용 목록에서 메일 구성 검사가 누락되어 비로그인 검사에 실패한 도구 설정도 합성 메일 구성으로 수정했다.

현재 원자료와 요약은 [raw.json](measurement-20261108-v2/raw.json), [summary.json](measurement-20261108-v2/summary.json)에 저장한다. 완료되지 않은 시행은 비교 수치에서 제외한다.

최종 무결성 검사에서 4회 완료·80개 고유 화면 표본·방식별 서버 설정 조회 20개, 현재 준비 callback 1회씩과 이후 callback 0회를 확인했다. 독립 검토에서도 산술·표본·해석·기록의 개인정보 범위를 대조해 차단할 문제를 찾지 못했다. 타입·린트·diff 검사도 통과했다. 측정 서버 3035/3036/3037은 종료했고, 측정 복사본의 fetch-cache만 확인 후 삭제했다. 원래 3034 서버의 health 200을 확인했다. 원자료·요약·CSV·빌드와 소스는 보존했다.

운영 Vercel, 사용자 집단, 실제 물리 디스크·IME, AI 품질·비용과 이번 측정을 혼동하지 않는다. 모델 호출 비용은 이 성능 검사에서 발생하지 않는다.

## 반복 API 테스트의 비용 구분

앞선 1,081개 자동 검사는 실제 OpenAI를 호출하지 않고 합성 응답으로 인증·동의·토큰 한도·오류·취소·본문 근거 검증을 수행했다. 실제 호출을 테스트 수만큼 실행하는 방식이 아니다. 일반 회귀는 합성 응답과 공개 합성 자료의 기존 응답 재생으로 반복하고, 실제 키 연결은 대표 1~3건부터 확인한다. 모델 의미 품질은 별도의 작은 평가 집합과 예산으로 검사한다. 합성 응답 통과가 실제 AI 품질을 입증하지는 않는다.

2026-11-08 공식 gpt-6-luna Standard 단가(입력 100만 토큰당 $0.10, 출력 $0.50)로 정리 생성의 현재 상한 8,192입력+3,200출력을 계산하면 생성 요청당 약 $0.0024192, 100회 $0.24192다. 도구·지역 처리·다른 처리 등급을 제외한 계산 예시이며 실제 청구 측정이 아니다. 별도 `/responses/input_tokens` 요청의 과금은 확인한 공식 문서에서 확정하지 못했다. 이 수치를 전체 요청 비용의 확정 상한으로 표현하지 않는다.
