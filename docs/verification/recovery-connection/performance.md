## 해석과 비용

정적 배포 자산은913858→1031247bytes(+117389)다. 기존에는 client에 연결되지 않았던 보관함 reader/Zod 스키마가 실제 연결 UI에서 사용되며 초기 JS 전송이 약32.8KiB 증가했다. 전체 배포 자산과 경로별 전송량은 서로 다른 값이며 표에서 구분한다. 이번 기능을 성능 최적화로 주장하지 않는다.

초기 화면 LCP와 설정 CLS에 상승도 관측됐다. 새 설정 내용이 초기 연결 로딩 후 표시되는 동작과 병렬 측정의 경쟁이 포함되므로 기능 자체의 순수 지연 증가로 단정하지 않는다. 같은 조건 순차 반복과 별도 프로파일 없이 전체 성능 향상/회귀 없음으로 보고하지 않는다.

신규 생성→연결 UI 시간은 browser/checks.json의 단일 OPFS 표본이다. 네이티브 디스크 성능, 안정적인 p95, 대규모 보관본 목록 성능으로 확대하지 않는다. 작은 식별 JSON만 읽고 쓴다. 백업 처리량·메모리, field INP, OS 권한창, 물리 입력은 미측정이다.
