# 데모 선택과 동의·편집 조작 보완

기준: `1fea66b`. 데모 전용 분류를 제거하고 사용자의 선택과 전송 동의를 명확하게 하는 변경이다. 기존 F1–F3, 인증 문제, 화면 2실패·taste 20지적은 이번 범위에서 해결했다고 보고하지 않는다.

## 원인과 변경

- 데모 폴더에만 별도의 분류 버튼·전송 동의·단계·전체 자료 선택이 있었다. 두 데모 페이지에서 분류 action 전달을 제거하고 해당 화면을 삭제했다. `FolderWorkspaceFrame`, `FolderListingView`, 파일 행·검색·선택 도구를 재사용한다. 실제 작업을 하지 않던 복사·이동 안내 버튼도 제거했다.
- 질문과 폴더 탐색이 정리 계획의 `selected`를 공유해 79개 같은 이전 선택이 질문에 따라왔다. `questionSelected`, `fileSelected`를 별도 보관한다. 질문 자료는 처음 웹사이트 문서 7개로 시작하며 사용자가 추가·해제한다. 최대 40개·발췌 6,000자 제한을 선택 단계와 상태 경계에서 검사한다. 선택을 모두 해제한 `[]`와 초기값 `null`을 구분해 새로고침에도 빈 선택을 유지한다. 구세션은 새 필드를 안전한 기본값으로 복원한다.
- 동의하지 않은 이유를 보여주지 않고 보내기만 비활성화했다. 체크 가능한 미동의 상태에 윤곽과 ‘자료를 보내려면 전송에 동의해 주세요’를 표시하고 체크박스의 설명으로 연결했다. 동의하면 강조를 없애며 질문·자료 변경 시 다시 동의를 받는다. 서버 전송 동의 계약은 유지한다.
- 기록 편집 폼의 세로 label 스타일이 승인 행에도 적용됐다. 공통 승인 행과 편집 버튼 배치를 재사용하고 승인 체크 크기 18px를 명시했다. ‘체험용’ 문구를 제거하고 취소는 공통 보조 버튼으로 변경했다.

## 남은 범위와 후속 전달문

데모 폴더의 원본 연결·복사·이동·휴지통·복구 전체 기능은 연결하지 않았다. 공통 탐색·검색·파일 선택·미리보기와 임시 자료를 사용하는 현재 범위다. 정식과 기능 전체가 같다고 주장하지 않는다. 사용하지 않는 분류 서버 action·상태 계약과 기존 테스트는 보존했다. 카탈로그의 ‘웹사이트 문서’ 경로가 바뀌면 기본 질문 선택은 빈 상태로 안전하게 닫힌다.

개인 폴더·운영 DB 직접 작업·추가 유료 AI·새 모델·새 패키지는 사용하지 않았다. 유료 검증 누적 추정은 13회·$0.0011481이며 계정 전체 청구액이 아니다. 실제 로그인·물리 IME·실제 원본 쓰기와 기존 화면 실패는 미검증/미해결이다.

다음 대화에서는 이 보고서와 `.omx/verification/demo-consent-folders-20261116/current-check.json`을 읽고 이후 diff부터 확인한다. 질문·폴더·정리 선택 분리와 빈 선택 복원, 동의 경계를 유지한다. 해결한 F1–F3 검사·수정을 반복하지 않는다. 폴더 전체 기능 동일화는 현재 완료 범위와 구분하고 실제 파일 시스템/임시 자료 경계부터 검토한다. 기존 개인 문서와 실패 기록을 보존하고 유료 호출·배포 실행은 최신 승인 범위를 확인한다.
