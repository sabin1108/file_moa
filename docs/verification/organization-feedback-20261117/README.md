## 변경과 리뷰 순서

1. `SelectionWorkspaceDialog`와 CSS: 범위·목적지·자료 선택이 재사용하는 공통 창이다. 목록 내부 스크롤과 창 본문 스크롤의 중첩을 제거하고 화면 높이를 제한했다. 본문에 키보드 초점/끝 여백을 주고 머리 조작과 하단 안내를 고정했다.
2. `ConversationWorkspace`/`useWorkspaceConversation`/`LiveConversation`: 새 정리 질문을 대화의 읽기 위치로 이동한다. 실제 pending 동안만 기존 작은 `MoaLoader`를 사용하고 완료/입력 확인 상태를 구별한다. 새 질문은 짧게 나타나며 움직임 감소를 따른다. 인위적 지연·모델 호출을 추가하지 않는다.
3. `SemanticModelPanel`: 설치된 상태의 기본 설명을 두 문장으로 줄였다. 준비 대상·실행을 먼저 표시하고 모델 관리·다운로드 출처·공유 범위·메모리·처리 한도는 상세에 보존했다. 설치 전에는 다운로드/메모리 필요량을 바로 알린다.
4. `organization-intent`/`organization-preparation-controller`/`connection-session`: 실제 이름을 먼저 확인하고 조사/루트 접두/역슬래시/구분자 주변 공백을 기존 경로 검증으로 해석한다. 정확한 깊은 경로는 해당 폴더만 직접 읽기 확인한다. 주변 목록이 불완전하면 마지막 이름만으로 확정하지 않는다. 모호한 이름·없는 폴더·경로 탈출·확인이 필요한 OS 절대 위치는 승인하지 않는다. 모델 추론이 아닌 로컬 이름 해석이다.
