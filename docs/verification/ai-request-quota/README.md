# 계정·작업 공간의 시간당 AI 요청10회

2026-11-09. 사용자가 ‘지금 한도는 10회 정도로 변경해줘’라고 요청했다. 앞서 확인한 일반 채팅/자료 정리의 계정·작업 공간 시간당3회를 각각10회로 올렸다. 샘플 전용 세션3회와 서버 전체 분당1회/시간당12회는 유지한다.

변경은 `server/chat.ts`, `server/live-organization.ts`의 예약 최대값4개와 두 화면의 안내 문구다. `consumeAll`의 기존 key/window·원자 rollback·중복 요청1회·실패/중지 예약 반환 없음은 유지한다. DB schema/실제 counter 삭제·초기화·자동 요청은 없다. 기존 사용 횟수가 있으면10회에서 이를 뺀 만큼만 추가 사용 가능하며 공유 한도에 먼저 막힐 수 있다.

채팅/정리 기존 경계 검사에 user/workspace 각각10회/3600초를 단언하고 수정 전2실패→수정 후 통과를 확인했다. 집중4파일56검사·전체129파일1210검사, 타입·린트·서버경계26/구조25+6+3·빌드 `__0_9_J88KO24SwSuQbhB`·diff 검사 통과. 실제 유료 모델 요청이나 실제 계정으로10/11회 호출하는 검증은 하지 않았다. 범위가 숫자와 안내 문구이므로 레이아웃/성능 측정·광범위 브라우저 검사는 반복하지 않았다.

현재 로컬 변경이며 커밋·푸시·배포는 하지 않았다. 최초3회 정책을 기록한 과거 보고는 당시 기록으로 보존하고 최신 명세 `general-chat.md`, `live-txt-md-consent.md`에 사용자 변경을 반영했다.
