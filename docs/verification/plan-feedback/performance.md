## 해석과 한계

이전은 바로 앞선 하위 검색/기록/선택 개선의 최종 측정이다. 정적 자산은885bytes 늘었으며 Zod 도입만으로 초기 전송이 크게 증가했다고 해석하지 않는다. 복구 식별 모듈은 현재 client import 경로에 연결되지 않았고 문자열 표식 검사도0이었다. 구조/번들 문맥을 함께 보며 문자열 검색만으로 포함 여부를 증명하지 않는다.

전송량과 배포 자산 합계를 구분한다. 소규모 lab 표본의 변동을 전체 속도 향상/무회귀로 확대하지 않는다. 6경로에는 미연결 파일 화면/시안/미구현 안내가 포함되며 실제 AI/로그인 성능이 아니다. 장기 heap 누수, 실제 사용자 INP, 개인 디스크/OS 권한창/물리IME·모바일은 미검증이다.
