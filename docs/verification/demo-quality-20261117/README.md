# 데모 중요도 정리 품질 보완 · 2026-11-17

사용자의 실제 문장 ‘내용별 중요성 별로 정리해줄래’를 중요도 처리에서 놓치는 조건을 회귀 테스트로 확인했다. 기존 조건은 ‘중요도/우선순위’와 명시적인 ‘상 중 하’를 모두 요구했다. 당시 사용자 요청의 원시 공급자 응답은 없어 그 오류의 단일 원인으로 확정하지 않는다.

데모 정리·자료 질문·대화만 서버 소유 프로필 `gpt-6-astra` / 추론 `medium`으로 올렸다. 기본 정식 정리·채팅은 기존 모델을 유지한다. 입력 토큰 계산과 생성은 같은 모델·추론·스키마를 쓴다. 새 의존성이나 자동 유료 재시도는 없다. 공개 횟수·문서·전송 동의 제한은 유지한다.

등급을 생략한 중요도 분류는 상·중·하 제안으로 처리한다. 명시적인 다른 등급·정렬·날짜·주제 조건과 자료별 답변은 우선한다. JSON/응답/계획 형식 실패 시 선택 자료를 유지하고 서버가 소유한 자료별 확인 질문으로 이어진다. 실패를 성공 계획·모델·사용량으로 꾸미지 않는다. 제외한 자료는 다시 묻지 않으며 세션·권한·한도 실패는 그대로 차단한다.

## 검증 근거

- 수정 전 3파일 59개 중 새 회귀 6개 실패, 수정 후 전부 통과. 최종 전체 제품·도메인 **184파일 1,688개 통과**. 추가 답변 프로필 연결 검사는 13개 통과했다.
- 타입 검사·빌드·경계 26개·구조 검사·S0 모듈 그래프 통과. 린트 오류 0, 기존 테스트 `_count` 경고 1개.
- 실제 OpenAI 호출은 안전한 제공 자료만 전송했다. 할당량 예약만 대체하고 세션·Origin·서버 소유 자료·응답 원문 인용·경로·등급 검증은 실제 코드를 통과했다. 개인 파일과 운영 DB는 사용하지 않았다.
- 실제 같은 문장: 20개에서 **19개 제안·1개 확인**, 전체 84개에서 **77개 제안·7개 확인**. 전체 5개 묶음 모두 형식 검증 통과. 본문이 비었거나 내용 판단 근거가 부족한 자료는 질문으로 남겼다. 사용자가 정리를 승인하거나 실제 파일을 옮긴 결과가 아니다.
- 실제 전체 자료 질문도 같은 상위 모델에서 성공했고 출처 인용을 검증했다. 로컬 진단에는 `.omx/verification/demo-quality-20261117/actual-{subset,all,answer}.json`을 보관한다. 생성은 총 7회이며, 초기에 샌드박스 네트워크 차단으로 외부 생성 전에 실패한 시도 1회는 구분한다.
- 실제 브라우저의 합성 오류에서 42개 선택 유지 → 공통 채팅 답변 → 자동 전송 없음 → 새 동의 뒤 42개 계획 검토까지 확인했다. 원본 위치는 유지됐다. `.omx/verification/demo-quality-20261117/browser.json`.

실제 모델 호출의 관측 시간은 부분 26.6초, 전체 56.8초, 자료 질문 14.5초였다. 단일 로컬 표본이며 모델·캐시·네트워크가 다른 과거 호출과 성능 비교하지 않는다. 전체 사이트 로딩·INP·메모리·물리 IME·개인 폴더·로그인 운영 DB는 이번에 재측정하지 않았다. 모든 표현이나 의미 판단의 정확성을 보장하지 않는다.

상위 모델은 비용이 높다. [공식 가격](https://developers.openai.com/api/docs/pricing)의 표준 입력 $10/백만 토큰, 출력 $50/백만 토큰 기준으로 추론 토큰도 출력에 포함된다. 실제 청구액은 별도다. API 호출 횟수 한도는 금액 한도가 아니다.

## 리뷰 순서

1. `shared/organization.ts`: 중요도 요청 판별과 기존 검증.
