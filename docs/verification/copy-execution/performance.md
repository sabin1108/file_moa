## 신규 복사 실행 비용과 한계

[최종 복사 검사](resume-20261102/final-copy/checks.json)에서16MiB×4=64MiB 복사 클릭→완료는 **1436.38ms, n=1**이었다. 원본/복사본 크기와 SHA-256 일치를 함께 확인했다. CDP 입력·왕복·30ms polling·권한 fixture·Worker·OPFS·journal 정산이 포함된 합성 관측이며 순수 I/O·INP·처리량 보장이나 p95가 아니다. [11월1일1273.93ms](browser/checks.json)와 오늘 표본은 서로 다른 실행이므로 개선율로 계산하지 않는다.

이번에는 새 복사의 최대 파일 수100개, 장시간 반복 복사·내용 대조의 메모리 추세, native OS 디스크/권한창, 외부 writer 경쟁, 실제 모바일, field INP, 공식 TBT, 서버/모델 부하를 측정하지 않았다. 최대64MiB 성공을 peak memory 예산 통과나 모든 크기/개수 조합의 성능 보장으로 확대하지 않는다. 복사 결과·재연결 내용 대조 기능 통과와 각 동작의 성능 표본 수는 별개다.
