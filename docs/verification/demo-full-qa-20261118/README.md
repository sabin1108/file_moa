## 읽기 불편 보완

실제 응답의 Markdown 표와 강조 기호가 그대로 보였다. `ConversationWorkspace`의 본문은 React 텍스트이므로 데모 `answerSample`에 짧은 문단·단순 목록의 일반 텍스트 출력을 요청했다. 렌더러·패키지·UI 재설계·정식 모델 변경은 없다. 모델 지침 준수에 의존하며 서버가 문법을 삭제하거나 실행하지 않는다. 배포 후 실제 재검증은 후속 절에 기록한다.

- `disk-filesystem.ts`와 `managed-files.disk.test.ts`: 제품 서비스에 실제 Windows 임시 디스크 I/O를 연결한 8검사. 폴더/빈 폴더 복사, 검증 뒤 이동 삭제, 휴지통/복구, BOM/CRLF 편집, 이름 충돌, 크기·시각을 맞춘 변경 감지, 취소 원본 보존, 경로 경계/쓰기 취소를 확인했다. 자체 `moa-managed-qa-` 폴더만 사용하고 정리 전 절대 위치·이름을 확인한다. 권한·핸들·Web Locks는 어댑터이므로 native 선택기 검증은 아니다.
- `sample-capacity.test.ts`: 100문서·50,000자의 준비/전송/적용/F5/되돌리기와 단일 이동 보존본, 101문서/50,001자 거부, 300노드/30보존본 및 초과 시 원자 거부를 확인했다.

## 계정과 자동 검사

현재 로그인된 실제 계정으로 세션 유효, `/login`→작업 공간, 설정·계정·채팅 이동, F5 후 동일 계정 유지가 통과했다. 설정/개인 파일을 변경하지 않았고 계정 식별값·메일·쿠키를 보고서에 저장하지 않았다.

일회용 PostgreSQL의 DB/권한/격리29검사와 이메일·소셜 통합4파일/60테스트 통과. 실제 Better Auth/DB를 사용하되 메일·OAuth는 모의 처리했다. 컨테이너는 정리됐다. 실제 메일 수신/소셜 재인증 완료로 주장하지 않는다.

전체 제품·도메인190파일/1,744테스트 통과. 표시 지침 보완 후 관련23파일/303테스트와 타입·린트·빌드 통과. 기존 `_count` 경고1개가 남는다. 서버 경계26·구조·S0 182모듈도 통과했다.

## 성능과 한계

100문서·5만자 Node 단일 관측: 준비7.6ms/적용27.8ms/복원21.9ms, 저장201,859자. 모델·디스크·브라우저 paint 지연이 아니다. Vite 브라우저 동기 갱신/레이아웃6표본은19.5~29.2ms였다. 빌드·테스트 종료 후 trusted click에서 두 프레임까지21.4~31.4ms, 긴 작업0건이었다.

초기 병행 실행에는 약1초 프레임 표본도 있어 보존했다. 빈 조작 비교7.3~11.4ms, 조건을 분리한 재측정에서는1초 지연이 재현되지 않았다. 원인·실사용 INP·속도 개선율을 확정하지 않는다. 메모리 수치도 GC/장치 비통제라 누수 증명이 아니다.

로컬 production6경로×2폭×3회(36표본)는 도착 경로 일치/가로 넘침 없음이었다. 같은 Ego 페이지·워밍된 캐시·100ms paint/CLS·공개 AI 비활성 조건이다. DOMContentLoaded 중앙값: 로그인42.8ms/소개35.8ms/비밀번호 재설정35.4ms/데모62.8ms/파일69ms/설정53.3ms. 비밀번호 재설정 CLS최대0.063245, 나머지0. 정적 JS/CSS54파일4,573,004bytes. 서버 출력 지침 보완 직전 관측이며 최종 자산은 별도 비교한다.

물리 IME·native OS 권한창·장기/모든 장치의 성능은 미검증이다. 이메일 수신/새 가입은 사용자 지정 수동 후속이며, 현재 계정으로 확인하고 실제 소셜 재인증은 실행하지 않았다.
