# 기능 소개 페이지 검증 — 2026-11-11

후속 사용자 요청으로 기본 등장 효과를 실제 스크롤 진행에 연결된 세 장면으로 보완했다. 현재 연출과 모바일·대체 표시·역방향 검증은 [최신 스크롤 연출 기록](../onboarding-scroll-motion/README.md)을 우선한다. 아래는 최초 소개 페이지 구현 당시의 기록이다.

## 구현

- 공개 `/start`, 공유용 `/demo/intro`에서 `components/onboarding/OnboardingPage.tsx`를 재사용한다. 기능 장면과 네이티브 자료 선택은 `ProductScenes.tsx`, 표현은 CSS Module에 둔다. 새 클라이언트 상태 계층이나 의존성은 없다.
- `demo/start`의 소개 경유와 명시적 시작만 추가했다. 기존 샘플 서명·쿠키·유효기간·실제 인증은 유지한다. 가입 화면의 공통 footer에서 공개 소개로 돌아갈 수 있다.
- 원래 작업 화면, 기존 시안, 체험 기능을 삭제하거나 재설계하지 않았다. 앞선 세션의 대규모 공백 변경과 이번 기능 변경을 구별한다.

## 참고와 스킬

사용자가 지정한 ego-browser로 https://lite.ego.app/ko 와 https://toss.im/ 를 실제 열어 제목·제품 지면·기능 장 구성을 확인했다. 외부 사이트의 로고·영상·문구를 제품 자산으로 복제하지 않았다.

design-taste: Colour chapters, seed 831972569. 기존 네이비·은회색과 시스템 글꼴을 유지했다. 사용자가 지정한 참고 방향에 맞춰 중앙 제목과 폴더 장면을 첫 화면에 두고, 이후는 밝은 지면·짙은 정리 장면·기록 지면으로 구분했다. 자체 자료와 실제 기능의 표시 조각 네 개를 사용한다. 별도 사진·영상은 이 제품의 실제 기능을 입증하지 않아 넣지 않았다.

사용자 추가 요청으로 공식 `jakubkrehel/skills`의 better-ui, better-typography, better-writing을 작업 폴더에 받아 읽고 적용했다. 팔레트·글꼴 교체 없이 조작 반응·움직임 감소·짧은 문구·줄바꿈과 크기를 검토했다. 전체 better-interface 검토를 수행한 것으로 주장하지 않는다. 전역 스킬 설정은 바꾸지 않았다.

표준 inspect.mjs 실행기는 이 환경의 Chrome 초기화에서 `Page.enable` 시간이 초과됐다. 스킬 소스를 수정하거나 검사를 통과한 것으로 숨기지 않았다. 같은 스킬의 probe/layout/judge/judgeLayout 함수를 실제 ego 페이지에서 실행했다. 마지막 5개 폭 모두 FAIL 0개였다. 이 대체 검사는 표준 실행기의 전체 스크롤 영화·모든 프레임 충돌 검사와 같지는 않다.

남은 자동 경고는 데스크톱의 사진/영상 부재와 일부 폭의 글자 외곽 기준 여백 차이였다. 사진 대신 제품 표시 조각을 사용한 이유는 위에 기록했다. 지면 컨테이너의 양쪽 padding과 중앙 정렬은 같으며, 여백 경고는 글자 끝과 스크롤바를 포함한 휴리스틱의 13~17px 차이다. 전체 페이지와 각 폭을 직접 확인했고 가로 스크롤은 없었다. 경고 기준을 완화하거나 검사 소스를 수정하지 않았다.

최종 일반 브라우저 폭에서 네 기능 지면 컨테이너의 왼쪽/오른쪽 여백은 각각 72px/72px였다. 마지막 검색 예시는 실제 키워드인 ‘정리 흐름’으로 맞췄고 재빌드·관련 10개 테스트·디자인 소스 검사 후 `/start`·`/demo/intro`·`/login`의 HTTP 200을 확인했다. 일반 소개에 noindex가 없고 공유용 소개에는 noindex/nofollow가 있다.

자체 시각 검토: design 8, usability 8.5, creativity 7, content 8, 가중 7.95/10. 큰 제목과 문서→폴더 모티프가 이어지고 기능별 구성이 달라진다. 사진·영상 대신 제품 장면을 사용한 조용한 소개이며 독립 심사 점수가 아니다. 생성 장면과 대화는 실제 사용 기록이 아닌 소개 예시다.

## 성능과 한계

최종 전체 static/chunks JS/CSS는 49개, 3,676,988 bytes다. 이번 변경 전 동일 조건 산출물을 따로 보존하지 않아 증감이나 속도 개선을 주장하지 않는다. 로컬 production `/start`의 재방문 단일 표본은 FCP 52ms, DOMContentLoaded 약 39.9ms, navigation duration 약 62.6ms, 문서 transferSize 9,913 bytes였다. 운영 환경·첫 방문·사용자 INP·사이트 전체 경로 수치가 아니다.

실제 200% 브라우저 확대, 물리 모바일 터치, 운영 배포와 새 실로그인·유료 AI 실행은 이번에 검증하지 않았다. 소개에서 모델 요청이나 파일 권한 요청은 하지 않았다. 생성된 `next-env.d.ts` 경로 변경은 원래대로 복원했다.
