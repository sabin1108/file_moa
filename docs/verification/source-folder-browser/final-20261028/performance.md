## 해석과 남은 범위

/files·/settings 및 다른 경로의 초기 전송 비용이 늘었다. /의 desktop LCP는 큰 변동(128–2376ms)이 있어 회귀 없음으로 판정하지 않는다. 브라우저 버전 변화·기능 추가·실행 변동을 분리하지 못했다. 최적화 완료나 사용자 체감 개선을 주장하지 않는다. 좁은 화면은 신규 기준선이다.

Lighthouse/TBT, 실사용 INP, 실제 모바일 장치, OS picker 대기, 서버 API 부하·AI 비용은 이번에 측정하지 않았다. 기존 도구와 Performance API만 사용했고 의존성을 추가하지 않았다. 목록 상태·정렬 완료와 성능 최적화 완료는 별개다.
