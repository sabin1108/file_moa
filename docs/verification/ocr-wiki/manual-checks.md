# 실제 환경 확인 순서

2026-11-10. 아래 항목은 준비된 확인 순서이며 아직 통과 결과가 아니다. 개발 서버는 `http://127.0.0.1:3034`이다. 사용자의 기존 로그인은 유지하며 비밀번호·인증 코드·세션 쿠키를 기록하지 않는다.

## 자동으로 확인한 범위와 남은 실제 확인

| 원래 번호 | 자동으로 확인한 범위 | 아직 남은 실제 확인 |
| --- | --- | --- |
|1 전체 흐름|제품 대화·검색·원문·기록·위키를 격리 브라우저에서 검사|실사용자 로그인 세션에서 전체 왕복|
|2 소셜 복귀|기존 합성 인증 검증과 사용자 로그인 완료 보고|실제 소셜 callback 후 복귀 직접 관찰|
|3 한글 입력|합성 조합 이벤트·공통 입력 보존|물리 키보드 조합과 줄바꿈|
|4 권한|취소/거부/철회 합성 실패에서 연결·원본 보존|Windows 실제 폴더 선택과 권한창|
|5 외부 변경|실제 OPFS 본문 변경·해시 불일치·복구 승인 무효화·두 탭 경합|외부 앱이 Windows 테스트 파일을 바꿀 때 감지|
|6 재시작|격리 Chrome 프로세스 완전 종료/재실행 뒤 IndexedDB 폴더 참조·OPFS 본문/버전 복원|실사용자 프로필의 선택 폴더 권한·여러 연결 복원|
|7 파일 작업|격리 OPFS의 복사22·관리32·복구43·재개35 검사|Windows 합성 폴더에서 실제 끝까지 실행|

S0 미완료였던 모듈 검사168개와 저장·복구30개도 후속에서 통과했다. 위 자동 결과를 아래 직접 확인 순서의 통과로 바꾸지 않는다. 실제 Windows 폴더를 연결하는 새 우회 adapter는 추가하지 않았다.

## 실제 확인 순서

개인 자료 대신 `.taste-skill/manual-ocr-wiki-20261110/`을 사용한다. `source-a`에는 합성 MD/TXT/PNG3개가 있고, `source-b`는 목적지, `ai-output`은 기록 저장 위치, `recovery`는 복구 위치다. 시작 해시는 `manifest.json`에 있다. 기존 개인 폴더는 이 확인에 포함하지 않는다.

1. **확장 경고:** Map-Dyoa 확장의 localhost 사이트 접근을 끄고 새로고침해 해당 hydration 경고가 사라지는지 확인한다. 앱에서 경고를 숨기지 않았다.
2. **로그인 복귀:** 사용한 로그인 방식과 작업 공간 복귀 성공 여부만 남긴다. 소셜 callback을 실제 관찰하지 않았으면 미확인으로 둔다. 추가 로그아웃을 자동 실행하지 않는다.
3. **물리 한글 입력:** 초안에 한글을 입력하고 조합 중 Enter·Shift+Enter를 확인한다. 불필요한 유료 요청을 보내지 않는다. 전송 의도가 없는데 문장이 전송되는지, 초안이 보존되는지 확인한다.
4. **Windows 폴더 선택:** 폴더 선택을 한번 취소하고 다시 `source-a`를 연결한다. 거부·연결 해제 후 기존 대화가 남는지 확인한다. 권한창은 사용자가 직접 선택한다.
5. **찾기·OCR·원문:** `회의 자료`를 찾아 MD 원문을 열고 돌아온다. 자료 설정에서 이미지 글자 읽기를 켜고 `글자인식.png`를 연다. 인식 결과는 원본과 비교하며 한 글자 오인식도 정상 한계로 기록한다. 원본 파일은 바꾸지 않는다.
6. **저장·재시작:** 별도 `ai-output`을 기록 저장 폴더로 연결해 대화/위키를 저장하고 재열기한다. 브라우저 완전 재시작 뒤 연결·권한 요청·기록 복원을 확인한다. 폴더 재연결만으로 외부 전송이나 쓰기가 자동 실행되지 않아야 한다.
7. **복사·이동·복구:** 합성 파일1개만 골라 `source-b` 목적지와 계획을 검토하고 별도 실행한다. 이동 시 보존본과 원본 상태, 복구 후 내용이 맞는지 확인한다. 개인 파일·기존 목적지를 덮어쓰지 않는다.
8. **외부 변경·철회:** 사용자가 합성 TXT에 문장 한 줄을 추가하고 앱에서 다시 읽었을 때 변경을 표시하는지 확인한다. 해당 연결의 권한 철회 뒤 실패 안내·초안 보존·늦은 결과 폐기를 확인한다. 이 작업은 실제 외부 앱과 사용자 권한 선택을 관찰해야 한다.

성공/실패·어느 단계인지·공개해도 되는 오류 문구만 기록한다. 실제 파일 경로·개인 본문·계정 정보·토큰·서버 원문 로그는 보내지 않는다. 합성 자동 검사와 실제 확인 결과는 별도 표로 남긴다.
