# 데모 현재 자료와 AI 연결 — 2026-11-18

요구사항 364. 정식 Luna 고정과 데모 Astra / medium을 유지했다. 기존 파일 사본과 고정 서버 카탈로그의 분리 계약을 변경했다. 개인 디스크·운영 DB·서버 자산은 변경하지 않는다.

## 변경과 읽는 순서

1. `files/sample-file-workspace.ts`: 기존 파일 트리를 카탈로그와 위치로 투영하는 함수를 파일 화면·채팅에서 공유한다. 여러 출발 위치의 AI 정리를 한 트랜잭션과 한 이동 보존본으로 반영한다.
2. `sample-state.ts`, `sample-workspace-store.ts`: 현재 자료를 질문·정리·검색·미리보기에서 사용한다. 실제 자료 변경은 준비/동의/오래된 결과를 무효화하고 체크 선택은 유지한다. 삭제 후 기록 참조를 보존하며 기존 분리 저장 상태를 이관한다. 적용·되돌리기·F5가 파일 노드를 함께 복원한다.
3. `shared/sample-materials.ts`, `server/demo/sample-answer.ts`, `server/demo/sample-organization.ts`: 선택 자료만 전송하고 서버에서 ID 일치·중복 경로·이름·100개/50,000자/262,144bytes를 검사한다. 인용과 분류 근거는 전송한 현재 발췌와 비교한다. 기존 세션·출처·동의·한도 예약·모델 검사를 유지했다.
4. `SampleConversation.tsx`, `SampleMaterialPicker.tsx`, `sample-preparation.ts`: 현재 문서 수·선택·내용·위치를 화면과 전송에서 일치시킨다. 편집 문서는 현재 내용으로, 복사 자산은 등록 자산으로 내려받는다.

파일 목록에서 발견한 행 높이 회귀는 공통 행의 `height: 100%` 두 곳을 제거했다. 42행 합성 목록에서 행 높이 약 2,511px, 페이지 약 126,654px이던 상태가 행 53px, 페이지 2,657px로 바뀌었다. 해당 CSS는 자동 높이 목록에 쓰이며 별도 고정 높이 가상 행은 없다.
