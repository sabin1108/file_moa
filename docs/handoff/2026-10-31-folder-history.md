# 2026-10-31 작업 기록 조회 인수인계

사용자가 다음 기능 안내 후 “진행해봐”, “작업 이어서해”로 승인한 현재 폴더 작업 기록 읽기 UI를 구현했다. 원본 생성 계약이나 삭제 계약은 확장하지 않았다.

- 현재 `/files`의 검색·선택 옆 작업 기록 버튼 → `.moa-history` 읽기 전용 팝업.
- pending/terminal 묶기, 모순·손상·부분 조회의 미확인 처리, owner/직계 경로 검증, 요청 취소/늦은 응답 폐기.
- [명세](../specs/folder-history.md), [검증](../verification/folder-history/README.md), [기능 코드 읽기](../reports/folder-history-reading-guide.md).
- 신규 관련31개, 전체278개 테스트와 타입/lint/경계/build 통과. 브라우저 신규27개+기존57개 통과. 실물 OS 권한/개인 자료는 미검증.
- 다음 후보는 재연결 후 미확인 작업의 실제 대상 존재를 읽기 전용으로 대조하는 기능이다. 현재 기록 조회는 존재 확인이나 복구가 아니다. 자동 재실행/삭제/복사/이동은 구현하지 않았다.
- 삭제는 기존 `docs/specs/entry-deletion.md` 계약 초안 상태다. 사용자 방식 결정 없이 실행하지 않는다.
