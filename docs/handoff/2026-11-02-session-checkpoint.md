- 목적지·계획 → 검사 → 실행/결과 단계, 검사 시각화/접힌 기술 정보, 깊이별 폴더 트리, 완료 확인 후 목적지 이동.

## 미구현과 다음 재개 후보

요구사항6~8의 전용 복구 보관함·검증된 백업 후 덮어쓰기·복원/기간/즉시 삭제는 계획만 있다. 현재 충돌은 의도적으로 차단한다. 실제 이동, 폴더 재귀 작업, 챗봇 분류/실제 AI/API·로그인·본문 저장도 미구현이다. 요구사항 원장은 완료 목록이 아니다.

사용자가 이어서 구현을 요청하면 `docs/specs/recovery-vault.md`의 보관함 기반 → 검증 백업 → 명시적 덮어쓰기 순서가 남은 후보다. 보존 기간/자동 정리 정책을 사용자 확정값으로 추정하지 않는다. 저장 요청만으로 다음 기능을 시작하지 않는다. 완료한 복사/기록을 다시 구현하거나 예전 필수 기록 폴더 선택기를 복원하지 않는다.
