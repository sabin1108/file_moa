# 미확인 작업의 현재 대상 확인 완료

사용자의 “다음 작업도 이어해줘”에 따라 작업 기록 조회 다음의 읽기 전용 현재 대상 확인을 구현했다. 최신 원본은 [명세](../specs/history-target-inspection.md), [검증](../verification/history-target-inspection/README.md), [기능 읽기](../reports/history-target-reading-guide.md)다.

미확인 행에서 현재 상태 확인 → 기록 재검증 → 대상 존재/종류 및 부모/핸들 대조 → 관측 시각 표시. 기록 자체의 결과는 변경하지 않는다. 재접속은 기존 명시적 다시 연결을 거치며 자동 권한 요청은 없다.

전체306개/28파일과 타입/lint/경계/build43 통과. 브라우저42+57=99개 통과. 추가 의존성/쓰기/대상 본문 읽기는 없다. OS 권한창·개인 디스크·실물 기기 검증은 별도다.

다음 후보는 실제 복사 실행의 계약이다. 기존 복사 전 검사에 실행 버튼을 바로 붙이지 않는다. 원본 변경·외부 충돌·쓰기 권한·부분 실패·취소·작업 기록·재시작 후 복구 경계를 명세와 실패 테스트로 정한 후 작은 단위로 진행한다. 삭제/이동/본문 저장/로그인/AI는 구현하지 않았다.
