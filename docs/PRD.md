# 제품 범위

## 2026-11-15 검색·RAG 후속

현재 소스는 필수/선호/구절/제외/형식/경로와 출처를 보존하는 검색 조건, 미지원 형식도 포함한 기기 catalog, 수동 갱신/파생 색인 삭제를 제공한다. 질문만 전송하는 AI 조건 제안은 기본 비활성이고 운영 migration/flag 적용은 미실행이다. MiniSearch/로컬 embedding은 합성 평가 후 비채택했으며 일반 의미 검색 기능의 완료가 아니다. [구현·평가·한계](verification/local-rag-20261115/README.md)

## 현재 구현 상태 — 2026-11-13

현재 소스에는 Better Auth 인증·workspace 격리, 로컬 폴더 탐색·편집·복사/이동·복구, PDF/OCR, 정식 채팅·선택 자료 질문·정리 제안, OpenAI/Gemini 공급자 연결, AI 기록·위키 보관 경로가 있다. [전체 코드 흐름](모아_전체_코드_흐름_설명서.md)과 [기술 경계](architecture.md)에서 실제 진입점과 호출을 확인한다. 기능별 실행 결과와 검증 한계는 각 검증 문서를 따른다. 소스·합성 검증·과거 실제 실행·현재 운영 검증을 같은 완료 상태로 취급하지 않는다.

정식 AI와 데모는 같은 DB·서버 비밀값 환경에서 전역 60초 1회·3,600초 12회 한도를 공유한다. 이는 비용 보호 정책이며, 데모 사용 때문에 정식 요청이 제한될 수 있다. 다중 사용자 운영 용량과 요금 정책의 완료를 뜻하지 않는다. [현재 한도와 검증 범위](verification/ai-request-quota/README.md).

아래 2026-10-25 결정은 당시 범위 기록이다. 현재 기능의 미구현 여부는 위 안내와 실제 소스로 판단한다.

## 이전 결정 — 2026-10-25
다중 사용자·브라우저 기반 서비스로, 사용자가 폴더 정리를 요청하거나 선택 자료로 보고서·이력서 등 문서를 만드는 것이 핵심 목적이다. Google·Naver·Kakao 로그인을 지원하는 방향이다. MD/TXT가 기본이며 PDF도 지원 대상으로 검토한다. 텍스트 PDF 우선, OCR·PDF 결과 내보내기 후속은 현재 제안 범위다.

사용자는 [개인 AI 로컬 보관 계약](specs/local-ai-storage.md)을 승인했다. 대화·승인 기억·결과물·작업 이력은 사용자 지정 AI 폴더에 보관하고, 서버 DB는 계정·세션·동의·사용량 등 운영 정보 중심으로 최소화한다. 모델·과금 방식·배포사는 아직 선정하지 않았다.

이 결정과 보관 계약이 아래 이전 단계 구분 및 원본 설계의 서버 보관 계획보다 우선했다. 당시 실제 제품 기능은 미구현 상태였다. 아래는 기존 개발 범위 기록이며 현재 구현 상태 안내와 구분한다.

## 이전 개발 기준
설계 v0.3 §25 기준. 자료 없는 대화도 지원하고 로컬 자료는 선택적으로 연결한다.

## P0
1. 세션·workspace 격리·서버 전용 모델 API.
2. 자료 없는 실제 대화, 스트림·중지·명시적 재시도·기록·한국어 IME.
3. 실제 로컬 폴더 2개 이상, 하위 탐색·파일명 검색·MD/TXT 미리보기·재연결·새로고침.
4. 선택 자료 전송 안내·색인·범위 제한 검색·출처 확인. 패널 왕복 시 초안/위치 유지.

## 완료 판정
설계 §25.6을 실제 브라우저로 검증한다. 초기 설정 페이지나 모의 응답으로 제품 완료를 판정하지 않는다.
권한 거부가 채팅을 중단하지 않고, 연결 해제가 원본을 삭제하지 않아야 한다.

## 후속
P1: 프로필·기억 승인·가상 분류·결과물·Kakao/Naver. 세 소셜 로그인은 공개 베타 전 완료.
로컬 AI·원본 변경·위키·성장은 별도 검증 후 진행.


## 사용자 목적 보정 — 2026-10-23
자료를 보는 것에 머물지 않고 파일 여러 개를 선택해 이동·복사·정리하는 사용 경험이 중요하다.
이번 디자인 시안의 완료 기준은 선택 수·일괄 작업·대상 경로·적용 전 계획이 명확한 것이다.
실제 파일 쓰기의 개발 우선순위·권한·충돌·복구 계약은 docs/specs/workflows.md에서 구체화하며 현재 구현 완료로 표시하지 않는다.

## 후속 편의 기능 — 2026-10-24
좌클릭을 길게 눌러 8방향 원형 메뉴에서 위치를 선택하는 빠른 이동: [기획](planning/radial-menu.md). 현재 프로토타입에 넣지 않는다.
파일 기본 뷰는 상위 폴더가 하위 폴더/파일을 감싸는 구조를 우선하며 출발/도착 폴더를 함께 식별할 수 있어야 한다.
사이트 성능 범위는 채팅뿐 아니라 모든 구현 화면·공통 자원·네트워크·메모리·서버를 포함한다. [측정 정책](performance-policy.md)과 [수치표 양식](performance-record-template.md)을 기능별로 적용한다.
