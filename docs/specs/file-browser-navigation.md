# 파일 탐색 기록과 파일 우선 화면 — 2026-10-29

사용자 요청: 마우스 뒤로/앞으로 버튼으로 문서 미리보기와 목록을 왕복한다. 모바일에서 검색·선택 설명이 파일보다 먼저 화면을 채우지 않게 하고 데스크톱의 사이드바와 중앙 카드 사이 낭비되는 여백을 정리한다. 다음 목적지 선택 기능보다 이 수정이 우선이다.

## 계약과 변경 계획

- NAV-001: 폴더 이동과 미리보기 열기를 브라우저 history에 추가한다. 뒤로/앞으로는 해당 폴더·문서를 복원한다. 미리보기의 목록 복귀 버튼도 같은 기록을 사용해 앞으로 가기로 재진입할 수 있다. 새로고침·검색 타이핑·선택 클릭마다 기록을 만들지 않는다.
- NAV-002: 목록 복귀 시 해당 목록의 검색어·선택·도구 열림·스크롤·가능한 파일 초점을 복구한다. 폴더를 다시 읽었다면 실제 확인한 파일만 재선택한다. 요청 중 뒤로/앞으로에도 늦은 결과가 현재 위치를 덮지 않는다.
- NAV-003: 기록에는 불투명 ID만 저장한다. 파일명/경로/핸들/본문은 URL/history.state에 넣지 않는다. Next의 기존 history 필드는 보존한다. 상세 기록은 Provider 수명의 메모리에 최대200개, 새로고침/소유자 변경/해제/연결 교체에 무효화한다. 낡거나 유효하지 않은 기록은 현재 안전한 화면으로 대체하고 권한 요청/연결을 자동 실행하지 않는다. 권한 상실 때 문서 읽기를 강행하지 않는다.
- NAV-004: /files 밖의 Next 경로 이동을 가로채지 않는다. 같은 Provider의 설정 왕복 뒤 /files로 돌아와도 유효한 기록을 복원한다. popstate listener와 스크롤 복원 설정은 화면 수명에 맞춰 정리한다.
- VIEW-001: 기본 연결 화면은 폴더 이름과 파일/하위 폴더가 중심이다. 검색 입력·긴 설명·선택 checkbox/전체 선택/계획 도구는 `검색` 또는 `선택`을 눌러 연다. 검색 닫기는 필터를 지우고 선택 닫기는 선택을 보존하며 버튼에 선택 수를 표시한다. 상태·권한 오류·부분 목록 경고는 감추지 않는다.
- VIEW-002: 파일 화면에만 중앙 카드 제한/중복 여백을 제거하고 주 작업 면을 사이드바 옆에 붙인다. 파일별 이름·종류는 조용한 행으로 정렬하며 가짜 크기/날짜/썸네일을 만들지 않는다. 모바일은 여백16px·조작44px, 390x844 기본 연결 화면에서 파일 첫 행이 상단60% 안에 나타나야 한다. 문서 본문 읽기 폭은 유지한다.
- VIEW-003: 도구 토글은 aria-expanded/controls, 입력 초점·닫은 버튼 초점 복원, IME·Escape, 선택과 미리보기 조작 분리를 유지한다. 연결 팝업은 compact 버튼으로 접근하고 기존 상태/오류를 재사용한다.

## 구현·검증 순서

기존 탐색/검색/선택 테스트를 회귀 기준으로 보존한다. 먼저 history port를 대체한 controller 테스트를 작성해 실패를 확인한 뒤 브라우저 adapter·화면 조합을 구현한다. 순수 탐색 수명과 DOM/history 접근을 분리하고 기존 session을 재사용한다. 원본 파일 변경·로그인·전역 폰트 교체를 포함하지 않는다.

실제 브라우저 history back/forward, 늦은 읽기·연결 교체·권한·화면 왕복·검색/선택·도구 접기·키보드·IME를 검사한다. 390/393/768/1440/1920px 화면과 파일 가시 높이를 측정하고 전후 초기 경로 비용/작업 비용을 기록한다. OS 마우스 드라이버 자체 검증과 브라우저 기록 동작 검증을 구분한다. 기존 색/서체/achromatic-ledger를 유지하며 파일 우선 구성과 연속된 작업 면이 이번 변경의 시각적 기준이다.
