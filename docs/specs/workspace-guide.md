# 계정 첫 사용 안내

2026-11-14 사용자 요구. 폴더 기본 조작·채팅·자료와 기록·대화 설정·전체 설정·퀵메뉴를 실제 화면에서 순서대로 안내한다. 기존 계정에는 새 안내를 일괄 재노출하지 않는다.

- GUIDE-001: 새 계정이 처음 작업 공간을 실제로 열면 계정 단위로 표시를 한 번 확보한다. 로그인 연결의 자료 소유자가 아니라 현재 로그인 계정을 사용한다. 동시 탭 중 한 곳만 확보한다.
- GUIDE-002: 안내를 닫거나 중간에 로그아웃하더라도 두 번째 로그인과 다른 기기에서는 자동 재노출하지 않는다. 최초 표시 시각은 서버에 저장하며 브라우저 완료 키로 자동 표시를 판단하지 않는다. 이미 존재하는 계정은 migration에서 표시 이력을 채운다.
- GUIDE-003: 화면별로 대상과 짧은 설명을 보여 주고 이전/다음/건너뛰기/완료를 제공한다. 폴더 선택·파일 변경·AI 전송·기억 승인을 안내가 자동 실행하지 않는다. 미연결 폴더는 실제 빈 상태로 설명한다.
- GUIDE-004: 폴더/채팅/설정 이동은 공통 이탈 보호를 거친다. 기존 초안과 선택을 유지하고 뒤로 가기에 안내 단계가 쌓이지 않게 한다. 사용자가 이동을 취소하면 현재 단계를 유지한다.
- GUIDE-005: 전체 설정과 대화 설정에서 다시 볼 수 있다. 다시 보기는 계정 이력을 지우거나 다른 계정의 상태를 변경하지 않는다.
- GUIDE-006: 인증되지 않았거나 Origin이 맞지 않으면 표시 이력을 변경하지 않는다. DB 오류가 기존 작업 공간 진입을 막지 않는다. 서버 claim 재시도/React 재실행으로 두 개의 안내가 열리지 않는다.
- GUIDE-007: 키보드 초점·Escape·작은 화면·스크롤 후 대상 위치를 확인한다. 대상을 찾지 못하면 잘못된 요소를 강조하지 않고 해당 화면의 설명을 유지한다.
- GUIDE-008: 일반 대화·자료 찾기·자료로 질문·자료 정리를 각각 언제 쓰고 어떤 순서로 사용하는지 설명한다. 안내가 현재 작업을 선택하거나 요청을 보내지 않는다.
- GUIDE-009: 기록함의 대화·결과물·위키·기억·프로필을 실제 탭으로 보여 주고 각각의 보관 목적과 만드는 경로를 설명한다. 임시 보기 뒤 기존 탭·검색·편집·저장 위치 상태를 복원한다. 파일 생성·승인·AI 전송을 하지 않는다.
- GUIDE-010: 안내문과 현재 강조 대상은 화면 안에서 겹치지 않는다. 퀵설정과 기록함·좁은 화면에서 실제 사각형으로 확인한다. 일반 단계 이동에서 같은 안내 dialog를 유지하고 이탈 확인이 있을 때만 잠시 닫는다. 강조 이동은 짧게 이어지며 움직임 감소 설정을 따른다.

회의록 그림은 별도 표시 수정이다. 기존 문서 예시와 종이의 크기·색·본문 크기·여백을 맞추고, 꺼내기 과정과 최종 읽기 상태를 함께 확인한다. 새 이미지나 의존성을 추가하지 않는다.
