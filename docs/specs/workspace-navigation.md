# 공통 탐색·간결한 대화·빠른 전환 — 2026-11-07

## 후속 사용자 수정 · 현재 기준

- WN-013: 자료 창은 열기와 닫기 모두260ms transform/opacity 전환을 제공한다. 닫기 완료까지 dialog를 유지하고 이후 닫기/초점 복귀한다. 연속 열기·닫기는 이전 animation을 취소해 역방향으로 이어가며 초안/대화/자료 DOM은 유지한다. reduced-motion은 즉시 전환한다.
- WN-014: 우측 상단 빠른 전환 버튼을 없앤다. 명시적 버튼 대체 조작은 설정 안의 퀵메뉴 미리보기로 옮긴다.
- WN-015: 퀵메뉴는 공통 작업 프레임의 opt-in 표시를 기준으로 채팅/폴더/설정 전체의 빈 영역에서 동작한다. 미래 작업 화면도 같은 프레임을 재사용하면 동작한다. 로그인/가입/비밀번호/소개/튜토리얼 등 opt-in 없는 화면은 마우스·단축키·열기 이벤트 모두 반응하지 않는다. route 변경 시 이전 gesture/timer/menu를 정리하고, 필요한 프레임은 quickMenu=false로 명시 제외할 수 있다. 입력/파일 선택/drag/modal/loading은 충돌 방지를 유지한다.

- WN-008: 실제/샘플 트리는 부모→자식 순서의 중첩 목록과 동일한 아이콘/펼침 열을 쓴다. 텍스트 길이로 아이콘 정렬이 달라지지 않으며 연결선·들여쓰기·현재 위치·긴 이름 title을 제공한다. 설정은 데스크톱 사이드바 하단의 계정 바로 위, 모바일 메뉴와 원형 메뉴에는 그대로 남는다.
- WN-009: 왼쪽500ms로 연 뒤 누른 상태에서 방향을 고르고 pointerup에 한 번 이동한다. 원 밖에서도 방향이 유지되며 중앙42px은 취소, 누르기 전8px 이동은 열기 취소다. 가장자리에서는 표시 위치만 보정하고 방향 기준은 최초 누른 위치다. pointercancel/blur/scroll/Escape는 이동하지 않는다. 키보드 호출도 누른 동안 방향/화살표 선택 후 호출 키를 놓아 실행한다. 화면 버튼으로 연 메뉴는 접근성 대체 클릭/Enter를 유지한다.
- WN-010: 단축키는 읽기 전용 입력에서 실제 키 조합을 받아 저장한다. modifier-only/조합 중/반복/Tab/Escape는 저장하지 않으며 Escape는 기록 취소다. 지원 가능한 문자·숫자·기능키·CapsLock 조합을 검증하고 기존 저장 값도 읽는다. OS/브라우저가 선점한 입력을 받았다고 가장하지 않는다.
- WN-011: 설정은 서버에서 인증한 DTO/패널을 받고 같은 경로의 탭은 native history+useSearchParams로 즉시 전환한다. back/forward/F5의 tab URL은 유지하고 privileged Action의 서버 검증은 유지한다. 계정 두 조회는 병렬화하고 탭 클릭마다 인증/RSC를 새로 요청하지 않는다.
- WN-012: 실제 페이지 이동 대기는 기존 로더를 재사용한 화면 중앙 상태 표시+어두운 backdrop으로 알린다. 빠른 로컬 설정 탭에 가짜 대기시간을 넣지 않는다. 애니메이션과 reduced-motion을 지원한다.

순서: 트리 정렬/방향·단축키 실패 회귀 → 공통 표시·입력 경계 수정 → 실제 컴포넌트/샘플 브라우저 → 타입·린트·빌드·경계와 최종 성능. 아래 명시 클릭/허용 조합3개 등 과거 계약은 이 후속 기준이 우선한다.

사용자: 대화/파일 사이드바를 같은 컴포넌트로 만들고 폴더 구조를 왼쪽에 표시한다. 미연결 시 대화에서 직접 연결하며 큰 빈 패널을 없앤다. 제목 전체 파란 초점 테두리를 고치고 키보드 안내는 유지한다. 로컬 제공 영상의 중앙 버튼/원형 펼침/이동하는 활성 표시를 참고하되 퀵메뉴는 폴더·채팅·설정 세 개다. 샘플은 회사/학교·논문/매출/방문수/통계/학습/개발·Excel 수치 자료로 확대한다.

## 수용 기준과 순서

- WN-001: WorkspaceSidebar/내비게이션을 대화·파일·설정에서 재사용한다. 모드별 라벨/경로와 안전한 폴더 트리 표시만 받으며 핸들·계정·샘플 저장소는 공유하지 않는다. 실제 폴더는 방문한 경로/현재 자식만 지연 표시한다. 전체 디스크 재귀 스캔은 없다.
- WN-002: 대화는 읽기 면과 입력을 중심으로 둔다. 파일 트리는 왼쪽, 자료/계획/미리보기는 요청/선택 시 여는 보조 영역이다. 기본으로 빈 오른쪽350px를 차지하지 않는다. 초안/대화/스크롤은 열기/닫기로 사라지지 않는다. 모바일은 닫기/초점 복귀 가능한 탐색 시트를 제공한다.
- WN-003: 실제 미연결 상태는 작은 연결 진입/직접 연결 버튼을 제공한다. 기존 Provider.connect/reconnect를 클릭 제스처에서 그대로 호출하고 취소/실패/성공 초점을 보존한다. 복구 보관함 전체 설정을 대화에 복제하지 않는다. 키보드 초점은 유지하되 프로그램 초점 제목의 전체 폭 테두리를 제거한다.
- WN-004: 원형 퀵메뉴는 폴더/채팅/설정만 이동한다. 중앙 닫기, 활성 표시 이동, 명시 클릭/키로 실행, Escape/외부 클릭 취소, 화면 가장자리 보정, reduced-motion을 지원한다. 보이는 진입 버튼과 단축키도 동일 메뉴를 연다.
- WN-005: 기본 마우스 왼쪽500ms·8px 이동 한계. 글자/입력/링크/버튼/파일 행/drag/modal에서는 시작하지 않으며 기존650ms 파일 선택과 충돌하지 않는다. pointerup/cancel/scroll/blur/문서숨김/해제 때 timer/listener를 정리하고 열기 직후 click만 억제한다. 터치/펜의 기존 동작은 보존한다.
- WN-006: 설정에서 길게 누르기/키보드/둘 다/끄기와 검증된 단축키 조합을 바꾼다. 기기 로컬 보관 실패 시 세션 내 값은 유지하고 안내한다. IME/repeat/편집 포커스에서는 전역 단축키를 처리하지 않는다. OS 전역 단축키 기능으로 표시하지 않는다.
- WN-007: 다양한 원본 합성 문서와 실제 수치 Excel을 제공하며 출처/합계/미리보기 일치를 검증한다. 평가 정답/holdout은 모델 입력에 넣지 않는다. 늘어난 전체 샘플은 로컬 내용 후보 검색 후 모델 최대40개/토큰 상한 안에서만 분석하고 분석 범위를 알린다. 등록 자료 외 본문은 받지 않는다.

기존 상태/계획/연결 회귀를 먼저 고정하고 바뀐 책임만 이동한다. 새 의존성 없이 구현 후 단위·타입·lint·경계·build,4폭/키보드/IME/길게누르기 충돌·취소/직접연결과샘플격리/초안보존/표/실파일 검증,최종성능을 기록한다. 영상 원본·키·실제 개인 자료는 앱이나 검증 산출물에 넣지 않는다.
