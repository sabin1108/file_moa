# 선택형 기기 의미 검색 — 2026-11-15

추가 동시성 계약: 원본 snapshot 잠금은 유지하되 모델 계산 동안 source WebLock을 점유하지 않는다. 저장 시 현재 본문 hash/parser/textLength와 scope/model epoch를 벡터/통계와 같은 IndexedDB transaction에서 재검사한다. 다른 탭의 기본 검색이 모델 계산을 기다리지 않아야 한다.

사용자 승인: 자료 찾기에 설치 진입점/사용 옵션, 전체 설정의 폴더 연결/로컬 검색에 설치·삭제·용량/폴더 준비를 둔다. 채팅 설정에는 추가하지 않는다.

- SEM-01: 기본 검색은 설치·다운로드·의미 색인 상태와 독립적으로 유지한다. 기본 화면/단어 검색에서 SDK import, 모델 Worker, 모델 네트워크는0이다. 다운로드와 자료 준비는 각각 사용자 조작이다.
- SEM-02: 모델 ID/revision/dtype/자산 hash를 고정한다. 전용 모델 cache와 same-origin WASM을 사용한다. 설치 모드에서만 공개 manifest 자산 GET을 허용한다. 설치 완료는 전체 자산 검증/모델 초기화 성공 뒤이며 취소/실패는 준비됨이 아니다. 추론의 cache miss는 외부 fetch를 막고 재설치를 안내한다.
- SEM-03: 모델은 이 브라우저에서 공유하고 본문/벡터는 owner/workspace/connection/path/hash/parser/model/chunk version으로 분리한다. 벡터에는 원문을 복제하지 않는다. 설치만으로 폴더를 읽지 않는다. 모델 삭제는 전용 자산만 지우고 의미검색을 중지하며, 연결 색인 삭제는 해당 scope의 벡터/통계도 원자 삭제한다.
- SEM-04: 설명 문장과 확인한 필수 조건을 분리한다. 모드 전환은 기존 조건을 자동으로 완화하지 않는다. 사용자가 설명과 필수 대상을 구분하고 확인한 뒤만 의미 후보를 추가한다. 명시 +/구절/제외/형식/경로/날짜를 원문 기준으로 유지하며 변경이 필요하면 원본 요청을 새로 작성한다. 고유 이름/기술 식별자 자동 삭제 금지.
- SEM-05: 의미 점수는 dev에서 고정한 임계값 이상인 후보만 채택한다. 0개인 질문에 topK를 억지로 채우지 않는다. 현재 원본 bytes/hash를 확인한 본문으로 필수/구절/제외/형식/경로/날짜를 검사한다. 의미 유사 후보를 전체 조건/정답 보장으로 표시하지 않는다. 기본 결과와 경로로 합친다.
- SEM-06: 자료 준비는 현재 읽기 권한과 원본 hash를 재확인하고 기존 추출 cache/Worker를 재사용한다. 500문서/50MiB와 별도의 구간 예산을 유지한다. 긴 글은 tokenizer로512token 이하로 나누고 부분 준비 범위를 표시한다. 권한/취소/변경/부분 읽기 실패를 완전 준비로 표시하지 않는다.
- SEM-07: generation·scope Web Lock·영구 epoch로 owner/연결 변경, 타 탭 clear, 모델 삭제 뒤 늦은 결과/벡터 재생성을 막는다. Worker 중지/삭제는 추론을 종료한다. quota/메모리/SDK/모델 실패는 명시하고 기존 조건의 기본 검색으로 돌아갈 수 있다.
- SEM-08: 실제 browser Worker·Cache·IDB의 설치 전 요청0/중지/재시도/재방문/cachemiss/정확한 삭제/scope 격리/다중 탭/현재 원본 변경을 검증한다. dev/holdout의 의미 회수·명시 조건·무관 후보, 기기 다운로드·초기화·추론·메모리와 UI1440/390·키보드·IME·production bundle/경로를 기록한다. 개인 자료·유료 API는 이 검사에 사용하지 않는다.

순서: 실패 테스트→순수 검색 계약/필터→자산/Worker→벡터 저장/수명→세션 연결→UI→실모델 비교/브라우저/정적 검증→기록. 새 라이브러리는 사용자가 승인한 모델 기능에 필요한 고정SDK 한 개만 추가한다.
