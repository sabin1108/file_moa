# 목적지 상대 경로 선택과 경고 표현 — 2026-10-29

2026-10-30 최신 확장: [최종 폴더 화면·실제 새 폴더](folder-workspace-revision.md). 탐색 controller 자체는 읽기 전용이며 별도 생성 폼/서비스가 사용자 요청으로 실제 새 폴더를 만든다. 따라서 아래 당시의 ‘새 폴더 생성 없음’은 최신 화면 전체에 적용하지 않는다.

2026-10-30 표시 개정: [목적지 선택·새로고침 UX](folder-controls-ux.md)를 함께 적용한다. 아래 탐색/권한/입력 계약은 유지하며, `연결 폴더` 독립 버튼은 경로의 최상위 이름으로, 확정 조작은 폴더 이름을 포함한 `이 폴더를 목적지로 선택`으로 바꾼다.

사용자 요청: 상대 경로를 직접 입력할 뿐 아니라 선택할 수 있게 하고, 경고에 분명한 색감을 부여한다. 기존 읽기 전용 변경 계획 안에서 연결된 폴더의 목적지를 고르는 기능으로 구현한다.

- DEST-001: `폴더에서 선택`을 누르면 같은 계획 dialog 안에서 현재 입력한 상대 경로부터 탐색한다. 입력이 문법상 잘못되었으면 연결 루트에서 시작하며 입력값은 확정 전까지 바꾸지 않는다. 루트/상위/직접 하위 폴더 탐색만 제공하고 파일은 목적지 목록에 표시하지 않는다.
- DEST-002: `이 폴더 선택`으로 확인한 폴더의 상대 경로를 입력에 반영한다. 루트는 빈 문자열이다. 선택은 기존 계획 결과를 폐기하며 다음 계획 생성이 실제 출발/목적지를 재확인한다. 직접 경로 입력도 유지한다.
- DEST-003: 탐색 중에는 메인 목록의 경로·파일 선택·브라우저 방문 기록을 바꾸지 않는다. 확정 전 계획 생성/작업 종류/직접 입력은 잠시 막는다. 선택 취소·Escape는 탐색만 닫고 이전 입력을 유지하며 시작 버튼으로 초점을 복구한다. 다음 Escape는 계획을 닫는다.
- DEST-004: 읽기 중/실패/이전 목록에서는 선택을 막는다. 실패 경로 재시도·루트 복귀·취소를 제공한다. 빈 폴더는 선택 가능하다. 1,000개 제한은 전체 항목에 적용되며 표시된 하위 폴더가 전체가 아님을 경고한다. 폴더 전체가 비었다고 잘못 말하지 않는다.
- DEST-005: 계획 닫기·목록/선택/연결/소유자 변경은 탐색도 닫고 읽기를 취소한다. 늦은 결과가 다시 열거나 입력을 덮지 못한다. 권한 상실은 기존 공통 권한 경로로 처리한다. 읽기 권한만 사용하고 파일 본문/쓰기/새 폴더 생성/외부 요청을 추가하지 않는다.
- WARN-001: 실제 공통 주의 상태는 명확한 황갈색 테두리/강조선·옅은 황색 면·진한 황갈색 문구/아이콘을 사용한다. 오류는 적색으로 구분한다. 계획의 파일별 충돌도 경고 아이콘과 문구를 함께 표시한다. 일반 안내/정상 결과는 경고색으로 칠하지 않는다.
- WARN-002: 색만으로 상태를 전달하지 않는다. 제목·아이콘·구체적 문제를 유지하고 실제 렌더링 대비(문자4.5:1 이상, 경계/아이콘3:1 이상)를 측정한다. 기존 채팅·파일 구성과 폰트는 유지한다.

기존 session의 목록 읽기를 재사용하고 목적지 탐색의 상태/취소는 별도 작은 controller로 분리한다. 명세 → 실패 테스트 → 구현 → 단위/기존 계획 회귀 → 실제 브라우저 키보드·390/768/1440/1920px·권한/지연/부분 목록·원본 보존 → 경로 성능 순서로 확인한다. 로그인과 실제 이동/복사는 포함하지 않는다.
