# 폴더 이동 조작과 팝업 안정성 — 2026-11-03

사용자 정정: 부모 이름/위치 설명을 더하는 문제가 아니라 처음 방문했을 때 상위 이동 조작의 형태를 알아보기 어렵다. 이동·복사 팝업의 깜빡임과 뻑뻑한 반응을 해결한다.

- NAV-018: 주 목록 첫머리와 목적지 경로 바로 아래에 같은 넓은 `위 폴더로` 행을 둔다. 위로 꺾인 화살표와 부모 이름을 표시하며 전체 행이 클릭/키보드 대상으로 작동한다. 루트에서는 표시하지 않는다.
- NAV-019: 목적지 경로 이동은 열린 탐색 면과 마지막 목록을 보존한다. loading 중 선택/생성은 금지한다. 실패는 이전 목록임을 알리고 재시도한다. 취소/권한 상실/늦은 응답 계약은 유지한다.
- NAV-020: 빠른 읽기는 로딩 안내의 삽입/제거로 목록 위치를 흔들지 않는다. 지연된 읽기는 고정된 상태 줄로 알린다. 경로 입력 DOM은 보존하고 경로 변경 시 값/오류만 초기화한다. 생성 폼은 위치별 수명을 유지한다.
- NAV-021: 목록/단계 교체에 전체 opacity/transform 진입 및 dialog 높이 애니메이션을 재생하지 않는다. 팝업의 위쪽 기준 위치는 단계별로 일정하며 내부 스크롤·Tab/Escape·초점 복귀를 유지한다.
- NAV-022: 파일/폴더의 선택 상태를 바꿀 때 새 설명 줄을 넣지 않는다. 오른쪽 종류 칸을 재사용하고 체크박스/선택 배경을 즉시 반영하여 아래 행 위치를 보존한다.

검증 순서: controller 전이/지연/실패/취소 회귀 RED → 구현 → Chromium 실제 프레임과 DOM 유지/연속 클릭/키보드/좁은 화면 → 기존 복사/탐색 회귀 → 타입/lint/build. 합성 권한·OPFS와 물리 장치를 구분한다. 이후 복구 보관함의 문서 검증 기반을 별도 단위로 진행한다.
