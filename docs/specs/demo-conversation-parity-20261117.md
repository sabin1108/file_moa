# 데모 대화와 자료 작업 연결

데모에서도 실사용 화면의 대화 질문, 전체 이력, 작성자 구분, 넓은 폴더·자료 선택창을 사용한다. 정리를 누르면 별도 첫 입력 없이 범위부터 묻고, 채팅 답변에 따라 하위 범위·기준·목적지를 하나씩 확인한다. 이전 질문과 작업 선택으로 돌아갈 수 있어야 한다.

샘플 카탈로그의 자료를 사용자가 직접 선택한다. 자동 추천 밖의 자료도 추가할 수 있고, 보낼 발췌를 확인한 뒤 명시적으로 동의해야 외부 AI를 호출한다. 정리 결과는 실제 제공된 발췌, 알려진 자료 ID, 날짜 근거, 확인한 답변으로 검증한다. 모호한 자료는 공통 또는 자료별 답변으로 다시 분석한다. 중요도 요청은 공용 상·중·하 계약을 따른다.

데모의 파일 변경과 복구는 세션의 가상 자료에만 적용한다. 개인 자료 폴더와 복구 보관함 연결을 요구하지 않는다. 공개 데모의 방문자·전체 일일 요청 한도, 세션·출처 검사, 자동 재시도 금지를 유지한다. 자료 수는 카탈로그 전체를 선택할 수 있는 최대 100개·50,000자이며, 정리는 공용 묶음 생성기로 처리한다.

검증은 카탈로그 전체 선택, 단계별 채팅과 뒤로 이동, 전송 전 무호출, 질문 답변 재분석, 중요도·근거 실패, 늦은 응답 무시, 적용·되돌리기 회귀를 대상으로 한다. 타입·린트·빌드와 실제 브라우저에서 넓은 선택창·스크롤·모바일·작성자 경계를 확인한다. 실제 외부 AI는 안전한 예시 자료로 제한된 대표 요청만 확인하며 모든 자연어 입력의 성공을 보장하지 않는다.
