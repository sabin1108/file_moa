# 튜토리얼 배경 회귀 수정

튜토리얼은 실제 작업 화면 위에서 안내한다. 공용 테마와 튜토리얼 스타일시트의 로드 순서와 관계없이 열린 전체 화면 dialog는 투명해야 하며, 강조 영역 안의 실제 메뉴·자료가 보여야 한다. 안내 상자의 배경과 바깥 음영은 유지한다.

운영 데모에서 작업 화면이 DOM에 있는데 dialog 배경이 불투명한 상태를 재현했다. 열린 튜토리얼에 배경 우선순위를 명시한다. 실제 브라우저에서 늦게 주입한 공용 테마 배경보다 투명 규칙이 우선하는지 확인하고 데모의 모든 안내 단계를 이동하며 작업 화면이 남는지 확인한다. 안내 취소·완료, 키보드와 좁은 화면도 검증한다. 원본 파일 접근이나 AI 요청은 필요하지 않다.
