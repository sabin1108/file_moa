# 모아 기능 소개와 체험 진입

## 대상

처음 방문한 사람에게 자료 찾기·자료 기반 대화·정리 계획·기록과 위키를 소개한다. 소개 화면에서 개인 파일을 읽거나 모델을 호출하지 않는다. 예시는 예시임을 표시한다.

## 경로와 계약

| 경로 | 동작 |
| --- | --- |
| `/start` | 공개 소개. 로그인·가입으로 연결하며 체험 링크는 렌더링하지 않는다. |
| `/demo/intro` | 공유용 소개. 로그인 없이 샘플 체험으로 연결하며 검색 제외 metadata를 제공한다. |
| `/demo/start` | 소개로 303 이동. `view=files`이면 소개와 최종 목적지까지 유지한다. 세션은 생성하지 않는다. |
| `/demo/start?intro=done` | 기존 샘플 세션 생성·유지 계약으로 진행한다. 실제 인증 쿠키는 변경하지 않는다. |

`intro=done`은 소개의 시작 조작을 구별하는 값이며 초대 자격이나 접근 권한 증명이 아니다. 체험 링크를 일반 소개에서 제공하지 않고 검색 제외를 설정하지만 URL을 아는 사람의 접근을 차단하지 않는다. 서명 초대·접근 제한은 이번 범위가 아니다.

## 실패와 보존 조건

- 소개 도착만으로 샘플 쿠키를 만들지 않는다. 링크의 Next prefetch가 체험 세션 생성을 앞당기지 않도록 체험 시작 링크는 prefetch를 끈다.
- 잘못된 view는 기본 대화 경로로 처리하고 외부 URL 목적지를 받지 않는다.
- 명시적 시작 시 유효한 샘플 세션은 유지하고 설정이 없으면 기존 503 응답을 보존한다.
- 기존 로그인·작업 화면·샘플 AI 사용 한도·원본 권한·외부 전송 확인은 변경하지 않는다.
- 자료 예시 선택은 네이티브 radio로 제공한다. 키보드 선택과 보이는 초점을 유지한다.
- CSS 스크롤 효과가 지원되지 않거나 움직임 감소 설정을 사용해도 모든 내용을 읽을 수 있어야 한다.

## 검증 연결

### 2026-11-11 스크롤 진행 연출

지원 브라우저에서 폭 360px·높이 820px 이상이고 움직임 감소가 꺼져 있으면 문서→폴더→작업 공간, 검색→원문→답변, 자료→계획 검토→정리 결과를 실제 스크롤 진행에 연결한다. 역방향도 같은 상태로 돌아가며 휠이나 키보드의 기본 스크롤을 가로채지 않는다. 제품 지면은 같은 크기의 영역에서 보완적인 마스크로 이어받아 겹쳐 비치거나 전체가 꺼지는 구간이 없어야 한다. 모바일 설명은 고정 영역 안에서 수직으로 이어지며 전환 구간은 20–40%, 58–78%다. 나머지 환경에서는 고정 지면과 겹침 없이 모든 설명과 장면을 순서대로 표시한다. 스크린리더용 단계 설명은 스크롤 위치에 관계없이 남긴다. [최신 전환 검증](../verification/onboarding-scroll-motion/continuity-correction.md).

`apps/web/tests/server/sample-routes.test.ts`의 소개 전 무세션·files 목적지 보존과 기존 쿠키/오류 검사, `apps/web/tests/onboarding/introduction.test.ts`의 공개/체험 진입 분리 검사를 사용한다. 실제 결과와 제한은 [검증 기록](../verification/onboarding-introduction/README.md)에 남긴다.
