# MD/TXT 원문 미리보기

2026-10-28. 구현 전 수용 계약. FILE-003은 연결 폴더 안의 한 파일을 명시적으로 열어 읽는 단위다. 파일 변경·전송·색인·Markdown HTML 렌더링은 포함하지 않는다. 기존 목록/연결과 같은 개발용 localhost 경계를 유지한다.

## 읽기 계약

| ID | 조건과 결과 |
| --- | --- |
| PREVIEW-001 | 루트 기준 파일 경로 배열을 복사·검증한 뒤 중간 폴더/파일을 create:false로 연다. MD/TXT(대소문자 무관)만 허용하며 경로 탈출·빈 경로·미지원 확장자는 I/O 전에 거부 |
| PREVIEW-002 | read 권한을 읽기 전/후 확인. 자동 requestPermission 없음. 권한 상실은 session과 연결/목록/미리보기에 반영하며 저장 참조나 원본을 삭제하지 않음 |
| PREVIEW-003 | domain의 파일당 2MiB 상한 재사용. 빈 파일과 정확히 상한은 허용, 초과는 본문 읽기 전에 거부. 읽은 바이트 수도 확인. 이 단일 파일 보기는 500문서/50MiB 색인을 허용한다는 뜻이 아님 |
| PREVIEW-004 | TextDecoder UTF-8 fatal. UTF-8 BOM은 제거, CRLF·공백·한글 그대로 유지. 잘못된 UTF-8은 오류로 표시하며 치환 문자로 성공시키지 않음 |
| PREVIEW-005 | 파일 삭제/폴더로 교체/읽기 실패 구분. 빈 본문은 성공한 0byte 파일에만 해당. getFile 이후 외부 변경에 따른 읽기 오류도 실패로 처리; 원자적 디스크 스냅샷 보장 아님 |
| PREVIEW-006 | 취소·닫기·새 파일 열기·계정 변경·연결 교체·해제·작업 영역 이탈 이후 늦은 성공/오류는 게시하지 않음. 진행 중인 OS I/O 강제 중단을 보장하지 않음 |
| PREVIEW-007 | 목록과 본문은 별도 요청 순번을 사용. 목록 조회가 같은 연결의 본문 읽기를 무효화하지 않으며 둘 다 연결 세대 경계를 따름 |
| PREVIEW-008 | 원본 쓰기/생성/삭제/서버 전송/본문 영구 저장0. 본문은 현재 미리보기 하나만 메모리에 보관하고 연결 수명 종료/닫기 때 해제 |

## UI 계약

| ID | 동작과 결과 |
| --- | --- |
| PREVIEW-UI-001 | MD/TXT 버튼의 클릭/Enter로만 본문 읽기. 목록 진입/이동/hover에서 본문 선읽기 없음. 미지원 파일에는 열기 버튼을 만들지 않음 |
| PREVIEW-UI-002 | 같은 작업 면에 파일명·본문을 우선 표시, 목록은 상태/DOM을 보존한 채 숨김. 목록으로 돌아가면 원래 파일 버튼 초점과 스크롤 위치 복구. 설정/대화 왕복은 열린 미리보기 상태 유지 |
| PREVIEW-UI-003 | 파일 정보 기본 접힘. 버튼으로 상대 위치·정확한 바이트·수정 시각·기기 내 읽기 상태 확인. 토글로 본문 DOM을 다시 만들지 않음 |
| PREVIEW-UI-004 | 새 파일을 읽을 때 이전 파일 본문 제거. 같은 파일 새로고침 중/실패/취소는 이전 읽은 본문임을 명시하고 보존. 재시도는 요청했던 파일, 재연결 후 열린 파일 재조회 |
| PREVIEW-UI-005 | 권한 필요 때 연결 관리 열림. 연결 선택 취소/저장 실패는 기존 읽기 보존, 교체 성공/해제 실패까지 포함한 해제 시작/소유자 변경은 즉시 비움 |
| PREVIEW-UI-006 | 원문은 React text node로 출력. HTML/script/Markdown 이미지/링크는 실행·외부 요청하지 않음. 본문 live region 없음. 16–17px/1.85행간/제한된 읽기 폭, 긴 단일 줄은 화면 안에서 줄바꿈 |
| PREVIEW-UI-007 | 읽기 진행·취소·재시도·빈 파일·크기 초과·UTF-8 오류·삭제·권한 오류를 안내. 읽기 완료/취소로 초점 요소가 사라져 body로 빠진 경우만 문서 제목으로 복구. 키보드, 390/768/1440/1920px와 상한 파일 검증. 입력창이 없어 IME 해당 없음 |

검증셋은 자체 작성 합성 이름·바이트·제어 가능한 Promise, 실제 OPFS 파일이다. 무작위 없음, 개발 회귀셋이며 holdout 아님. 테스트에서 제품 session/controller/reader를 실행하며 브라우저 권한/picker만 대체한다. 개인 파일을 테스트에 사용하지 않는다. 명세→실패 테스트→구현→회귀·브라우저 검증 순서와 미검증 경계를 기록한다.
