# 데모의 안내와 전체 작업 체험

## 후속 정정 — 진입·자료 선택·인증 실패

- DEMO-107: 명시적인 ‘체험 시작하기’ 진입은 기존 세션/자료를 교체하지 않고 기존 안내를 한 번 연다. 문서 이동으로 쿠키 발급 후 레이아웃을 읽으며 `guide=1`은 표시 시 소비한다. 새로고침·일반 화면 이동은 다시 열지 않는다. 안내 저장소가 막혀도 명시 진입/설정 재생은 작동하며 자동 재표시는 하지 않는다.
- DEMO-108: 자료로 질문 시작 시 선택이 0개면 공통 파일 목록을 자료 선택 상태로 연다. 파일만 직접 체크하고 선택 완료 후 입력창으로 초점을 돌린다. 선택 전 전송은 막고, 선택한 발췌와 출처만 제공한다. 자료 선택에 없는 폴더 선택·복사/이동 기능을 노출하지 않는다.
- DEMO-109: 설정 재생은 공통 설정 행/버튼을 사용한다. 익명 로그인 진입은 세션 쿠키가 없으면 인증 SDK를 초기화하지 않는다. 쿠키가 있으면 기존 SDK 검증과 실패 전파를 유지한다. 로그인 오류 화면은 재시도/데모 복귀를 제공하며 내부 오류나 로그인 성공을 표시하지 않는다. 실제 인증 설정/DB 연결의 정상 여부는 별도 검증한다.

## 최신 정정 — 실제 제품 화면과 설명 공유

사용자는 별도 데모 튜토리얼·기본 컨트롤·설명 없는 예시와 초기 체크를 거절했다. 같은 제품 화면을 보여주고 데이터만 예시 폴더로 바꾸는 방향이 우선한다. DEMO-104의 별도 짧은 안내는 기존 17단계 `WorkspaceTour` 공유로 대체하며, 새 상태/초기화의 자동 선택은 금지한다. 실제/데모 공용 작업 컨트롤·설명·컨텍스트·기록 탭/필드·파일 목록이 변경의 기준이다. 동작 어댑터의 남은 차이는 감추지 않는다. ## 완료 조건

- DEMO-101: 실제 ConversationStart의 작업 목록을 공유해 일반 대화·찾기·정리·자료 질문으로 진입한다. 준비된 응답과 실제 모델 호출을 구분한다. 기본 체험은 외부 전송 없이 가능하다.
- DEMO-102: 찾기는 기존 질문 해석·검색 판정 규칙으로 샘플 발췌와 현재 가상 경로를 검사한다. 기간이 불명확하면 조건 확인을 안내한다. 자료 질문은 선택한 샘플만 인용하고 원문을 열 수 있다.
- DEMO-103: 공용 대화 화면을 재사용한다. 샘플 기록함에서 대화 보관·열람·결과물·위키·기억·프로필을 이 탭의 임시 기록으로 체험한다. 정식 기록함은 실제 폴더 저장과 결합돼 있어 끌어오지 않는다. 실제 폴더 저장·운영 모델 검증과 혼동하지 않는다.
- DEMO-104: 짧은 안내는 이전·다음·건너뛰기·다시 보기를 제공한다. 실제로 작업을 실행하거나 동의하지 않는다. 안내 후 기능별 자유 체험과 작업 예시를 제공한다.
- DEMO-105: 새로고침과 대화/파일 왕복에서 모드·초안·완료한 작업·기록을 복원한다. 정리 검토 중 모드 변경은 계획을 보호하며, 취소·만료·저장 불가·잘못된 상태·초기화는 개인 자료에 영향을 주지 않는다.
- DEMO-106: 공용 작업 목록과 실제 UI를 공유해 변경 누락을 줄인다. 데모와 정식 제품의 기능 대응/미지원 범위를 명시하고 기존 sample 검증에 새 작업 회귀를 추가한다.

## 경계와 구현 순서

샘플 세션과 카탈로그를 유지한다. 읽기/검색·샘플 응답 상태 회귀를 먼저 실패 확인하고 최소 구현한다. 샘플 기록은 같은 상태 검증과 탭 보관 경계를 사용한다. UI는 기존 토큰·프레임을 사용한다. 기존 AI 버튼의 동의 계약은 유지하되 이번 검증에서는 호출하지 않는다. 실제 인증·권한창·개인 폴더 쓰기·운영 DB·유료 AI·모델 다운로드·배포·커밋·푸시는 실행하지 않는다.

기존 화면 2실패·taste 20지적은 별개 이력으로 유지한다. 실제 폴더 연결/편집/복사/복구와 실모델 품질은 데모의 지원 범위 안내로 구분하며, 이 변경으로 운영 검증 완료를 주장하지 않는다.

## 검증 순서

추가 회귀의 실패 → 관련 sample/기록함 검사 → 타입·린트·전체 검사·빌드·구조 검사 → 합성 샘플 브라우저와 키보드/390·768·1440 검증 → 독립 검토. 브라우저 검증에서는 외부 AI를 비활성화하고 개인 파일 API·운영 DB를 호출하지 않는다. 미실행·실패는 그대로 기록한다.
