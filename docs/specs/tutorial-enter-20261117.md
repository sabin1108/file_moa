# 튜토리얼 Enter 이동

열린 튜토리얼의 제목·안내 영역에서 수정 키 없는 Enter를 누르면 현재 ‘다음’과 같은 동작을 수행한다. 마지막 단계에서는 ‘완료’와 같다. 화면이 준비되지 않았거나 키 반복·IME 조합·이미 처리한 이벤트이면 이동하지 않는다.

입력칸·여러 줄 입력·선택 상자·편집 영역의 Enter는 보존한다. 이전·건너뛰기·다음 및 링크처럼 직접 초점을 받은 조작은 기존 기본 동작을 유지하며 중복 이동하지 않는다. 키보드 이벤트는 튜토리얼 dialog 안에서만 처리한다.

검증은 실제 공용 오버레이를 사용하는 브라우저 fixture에서 Enter 이동·완료, 네이티브 버튼, 폼 제출, 줄바꿈, 합성 IME, 준비 전 차단을 확인한다. 배포 후에는 실제 데모의 19단계를 Enter로 이동하고 완료 후 복귀를 확인한다.
