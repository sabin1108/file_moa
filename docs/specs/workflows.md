## 최신 저장 계약 — 2026-10-25
사용자가 승인한 [개인 AI 로컬 보관 계약](local-ai-storage.md)을 적용한다. 대화·승인 기억·결과물·작업 이력의 로컬 보관, 임시 대화, 기억 범위, 삭제·충돌·계정 격리의 LOCAL-001~010은 구현 전 수용 기준이며 테스트 통과 기록이 아니다. 과거 서버 본문·기억 영구 저장 전제는 이 계약으로 대체한다. DATA-001의 동의·격리·삭제 후 늦은 작업 차단 원칙은 유지한다.

## FILE-001: 여러 파일을 정리한다
목적: 사용자가 여러 파일을 선택하고 이동/복사/분류할 계획과 결과를 이해한다.
Given: 허용된 폴더와 파일 3개. When: 대상 폴더와 작업을 선택.
Then: 선택 수·출발/도착 경로·충돌·예상 결과를 먼저 표시. 원본은 아직 바뀌지 않는다.
적용 단계는 명시적 사용자 실행, 쓰기 권한, 원본 hash 재검사, 경로 탈출/동일 이름 충돌 검증, journal 및 실패 복구를 갖춘 후 구현한다.
여러 파일 작업은 원자적이라고 가정하지 않는다. 일부 실패/취소 시 각 파일의 성공·실패·미실행을 표시한다.
복사는 원본 보존, 이동은 대상 검증 뒤 원본 삭제. 동일 이름 자동 덮어쓰기 금지.
분류가 가상 모음인지 실제 이동인지 작업 이름과 미리보기에서 구분한다.
2026-10-29 실제 구현: 현재 폴더의 실제 파일 선택 → 이동/복사/확장자 분류 → 출발/도착 목록 재확인 → 계획 검토/충돌 안내/취소. [PLAN-001~008](file-change-plan.md). 원본 적용은 미구현이다. 과거 React 폴더 3개 예시는 `/preview`에만 남는다.

## CHAT-001: 긴 한국어 답변을 읽는다
본문 16–17px, 행간 1.8–2.0, 읽기 너비 약 620–720px부터 확인한다.
밝은 회백색 본문과 네이비 탐색 영역을 구분한다. 자료 본문은 기본 화면을 점유하지 않는다.
390/768/1440px에서 가로 넘침·입력창 겹침·200% 확대·키보드·긴 단락 읽기를 점검한다.
Lighthouse나 대비 수치가 눈의 편안함을 보장하지 않으므로 사용자 피드백을 함께 판정한다.
실제 채팅 구현 시 IME 조합 중 전송 차단, 패널 전환 시 초안/선택/스크롤 유지.
