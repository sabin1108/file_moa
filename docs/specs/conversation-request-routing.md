# RQ-001~005: 검색과 정리 요청 전환

2026-11-08, 요구176. 기존 후속 목록2번. 검색 조건의 채팅 답변·새 날짜 표현·검색 결과 정리 연결은 이후 작업이다.

- RQ-001: 명확한 찾기 요청은 기존 검색 조건 확인으로, 정리 요청은 기존 자료 준비로 연결한다. 혼합·부정·알 수 없는 새 요청은 먼저 ‘자료 찾기/자료 정리’를 선택한다. 제한된 로컬 표현 판별이며 일반 의미 이해가 아니다.
- RQ-002: 선택 전에는 새 파일 탐색·읽기·AI 전송·원본 변경을 시작하지 않는다. 선택 취소는 작성 중인 문장을 보존한다. 현재 확인 질문의 답변은 기존 답변 처리로 보내며, 새 요청으로 바꾸려면 기존 ‘최초 정리 요청 수정’을 사용한다.
- RQ-003: 검색 전환은 기존 정리 cancel로 동의·제안·늦은 응답을 폐기한다. 정리 전환은 기존 검색 reset으로 늦은 검색을 폐기한다. 실제 파일 적용 중이거나 연결이 유효하지 않으면 전환하지 않는다. 새 정리도 외부 AI 전송·원본 적용은 기존 별도 확인을 거친다.
- RQ-004: 검색 화면에서도 새 요청을 입력해 검색과 정리로 전환할 수 있다. 선택 UI/버튼/간격/대화 입력·IME 처리·원문 보기·컨트롤러 취소 규칙을 재사용한다. 선택 창은 일시적인 화면 상태이며 요청 초안·확정 조건은 기존 Provider 소유로 유지한다.
- RQ-005: 순수 판별/전환의 실패 조건, 실제 컨트롤러의 동의 폐기·늦은 결과·진행 중 적용 차단, 두 화면의 선택·취소·키보드·좁은 화면·합성 IME·네트워크/쓰기0을 검증한다. 실제 Windows/물리 IME·유료 모델 호출은 별도다.
