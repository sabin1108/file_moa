# AI 공급자 연결

## 범위와 선택

서버의 `AI_PROVIDER`로 `openai` 또는 `gemini`를 선택한다. 미지정이면 OpenAI 키가 있을 때 OpenAI, 없을 때 Gemini를 선택한다. 명시 설정이 잘못되거나 선택한 키가 없으면 요청을 차단한다. 실패 시 다른 공급자로 자동 전환하지 않는다.

OpenAI는 기본 fetch와 Responses REST를 사용한다. 새 SDK 의존성은 추가하지 않는다. 기본 모델은 `gpt-6-luna`이며 데모의 정리·대화·자료 질문은 서버가 선택하는 `gpt-6-astra`, 추론 `medium`을 사용한다. 클라이언트에서 모델을 지정하지 않는다. 기존 Gemini 모델과 정책을 유지한다. 양쪽은 같은 정리 지침과 JSON Schema를 사용하고 결과의 본문 근거·경로 검증을 재사용한다.

## 계약과 실패 조건

- OAI-001: 키는 서버 전용 헤더로만 전송한다. 요청·결과·로그·브라우저에 키를 포함하지 않는다. OpenAI 요청은 `store:false`, 도구 없음, 출력 상한, no-store, redirect:error다.
- OAI-002: 모델·추론·지침·입력·스키마를 같은 값으로 토큰 계산과 생성에 사용한다. 입력 상한을 넘으면 생성을 호출하지 않는다. 응답은 출력 토큰에 비례한 64~256KiB 상한, 완료 상태·거절·JSON·usage를 확인한다. 취소·429·잘못된 응답·출력 중단에 자동 재시도하지 않는다.
- OAI-003: 페이지가 표시한 공급자를 Server Action에 고정한다. 현재 서버 설정과 다르면 할당량 예약·외부 호출 전에 거부한다. UI도 공급자가 바뀌면 기존 전송 확인을 재사용하지 않는다.
- OAI-004: 샘플·정식 요청은 기존 인증·Origin·동의·멱등성·공유 할당량·원본 재검사·공개 직전 세션 검사를 유지한다. 설정 조회 자체로 외부 요청을 하지 않는다.
- OAI-005: 자연어 요청 전체에서 분류·필터·제외·수정·사용자 지정 이름과 계층을 해석한다. 중요도 등급을 생략하면 기본 상·중·하를 제안하되 다른 조건을 덮어쓰지 않는다. 요청에 중요도·보고서·성능이라는 단어가 있다는 이유로 서버가 해당 분류를 강제하지 않는다. 분류의 의미 정확성은 모델 평가와 사용자 계획 검토로 확인하며, 서버는 자료 ID·원문 인용·안전한 경로·날짜 근거·사용자 확정 답변을 검증한다. 모델의 해석을 검증된 사실이나 모든 표현에 대한 보장으로 취급하지 않는다.
- OAI-006: 데모 정리의 JSON·응답·계획 형식 실패는 원문 자료에 대한 확인 질문으로 이어지며 성공 계획·모델·사용량을 만들지 않는다. 자료 선택은 유지하고 답변 후 새 동의와 명시 전송을 받는다. 세션·권한·한도 실패는 이 복구 경로로 우회하지 않는다. 유효한 응답이어도 제안과 보류 자료가 모두 없으면 요약의 확인 내용을 표시하고 채팅으로 기준을 다시 묻는다. 새 기준을 받기 전 전송 조작은 숨긴다. 답변 후 자료 확인·새 동의가 필요하다.

2026-11-17 모델·구조화 출력·추론 설정 근거: [공식 모델 선택](https://developers.openai.com/api/docs/guides/model-selection), [최신 모델 안내](https://developers.openai.com/api/docs/guides/latest-model), [구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses). 실제 제공 자료 검증과 한계는 [데모 품질 검증](../verification/demo-quality-20261117/README.md)을 따른다.

후속 일반 요청 처리와 대표 의미 평가: [다양한 데모 요청 검증](../verification/demo-general-intent-20261117/README.md). 이전 중요도 전용 정규식·응답 등급 강제·누락 날짜 보정은 이 후속 변경에서 제거했다.

## 검증 계획

공급자 선택/누락/불일치, 합성 REST 응답 성공·토큰 초과·거절·미완료·비정상 usage·과대 응답·취소·오류를 테스트한다. 기존 샘플/정식 경계 테스트와 전체 타입·린트·빌드를 실행한다. 브라우저에서 공급자 표시·동의 후 전송·바뀐 공급자의 동의 재사용 차단을 합성으로 확인한다.

실제 API 품질·비용·Vercel 환경변수 및 배포 적용은 합성 검증으로 입증되지 않는다. 프로젝트의 $10 한도는 외부 플랫폼 설정이며 앱의 요청 횟수 제한과 별개다.

## 공개 샘플의 비용 사용

공개 배포의 샘플 AI 전송은 기본 비활성이다. `ENABLE_PUBLIC_SAMPLE_AI=true`를 서버에 명시해야 허용한다. 키 추가만으로 공개 샘플이 켜지지 않는다. 로컬 HTTP loopback 앱은 기본 허용하며 false로 끌 수 있다. Vercel 환경은 로컬 URL이 잘못 남아 있어도 기본 비활성이다.

샘플 페이지 표시와 `reserveSampleAi`/분류 서비스가 같은 정책을 검사한다. Action 직접 호출도 할당량 예약·모델 호출 전에 거부한다. 로그인한 사용자의 정식 AI 설정은 별도로 유지한다. 명시적으로 공개 전송을 켜면 기존 전역 횟수 한도를 정식 기능과 공유하므로 운영자가 비용과 사용 가능 횟수를 함께 판단해야 한다.
