# OCR와 출처 연결 위키

2026-11-10 사용자 승인 범위: 직전 목록1~7의 실제 환경 검증,15 OCR,18위키. 실제 검색은 키워드 검색을 유지한다. 로컬 AI와 Kakao는 이번 범위에서 제외하며8~14·19·21·22는 보류한다. 브라우저에서 OCR을 실행하는 것은 기기 내 생성 모델을 추가하는 로컬 AI 기능과 구분한다.

## OCR

- 승인한 `tesseract.js@7.0.0`과 한국어·영어 인식 파일만 추가한다. 후원 안내 postinstall은 실행하지 않는다. 엔진·Worker·WASM·인식 파일을 같은 origin에서 제공하며 이미지/PDF 바이트를 서버나 CDN에 전송하지 않는다.
- 기존 PDF.js와2MiB·50쪽·200,000자·읽기 권한·해시 검증을 유지한다. 텍스트 레이어 없는 쪽과 PNG/JPEG 이미지를 대상으로 제한된 OCR을 수행하고, OCR 결과·부분 추출을 원문 텍스트 레이어와 구분한다.
- OCR은 이미지 크기·처리 쪽수·시간 상한을 두고 Worker를 종료해 중단한다. 늦은 결과 게시를 막으며 OCR 결과를 확정 사실로 취급하지 않는다. 추출 텍스트를 외부 AI에 보내는 것은 기존 발췌 확인·동의 경계를 따른다.
- 실패 조건: 손상/과대 이미지, 텍스트 없음, 언어/엔진 파일 부재, 취소·시간 초과, 잘못된 UTF-8 기존 경계, 변경/권한 철회, 외부 요청0. 실제 한국어·영어 이미지와 스캔 PDF를 합성해 엔진 결과를 검사한다.

## 위키

- 기존 결과물 저장 형식에 선택적인 위키 메타데이터를 추가해 이전 기록과 호환한다. 별도 원본 쓰기나 DB 이관을 만들지 않는다.
- 검증된 자료 답변에서 위키 초안을 만들며 연결된 원본의 owner·연결ID·경로·해시·크기·인용문, 생성 시각·모델(미확인은null)·생성 버전을 보존한다. 출처 없는 답변은 출처 연결 위키로 저장하지 않는다.
- 기존 기록함 안에서 위키 목록·검색·편집·저장·버전·내보내기·삭제를 제공한다. 원문 열기/출처 재확인은 현재 폴더·권한과 해시를 다시 확인한다.
- 출처 변경은 갱신 필요, 연결/권한 부재는 확인 불가로 구분한다. 마지막 확인은 그 시점의 결과이며 실시간 파일 감시를 보장하지 않는다.
- AI 초안과 사용자 편집 본문을 구분한다. 기존 위키에 새 자료 답변을 연결할 때 새 초안을 제안으로 보관하고, 명시적 반영 전 사용자 본문을 바꾸지 않는다. 반영/편집도 기존 불변 revision에 새 버전으로 저장한다.
- 실패 조건: 거짓 출처/추가필드, 원본 변경·삭제·다른 연결, 읽기 취소/늦은 결과, 사용자 수정본 자동 덮어쓰기, 저장 실패·경합·삭제 후 부활,390px·키보드·합성IME. 인용문 일치 검증이 모든 주장 내용의 사실성을 증명하지는 않으므로 초안 검토를 유지한다.

실제 소셜 인증·Windows 권한창·물리 한글 입력은 사용자 직접 확인이 필요하다. 현재 사용자 로그인 완료 보고를 받았으나 컴퓨터 사용 도구가 Chrome URL을 판별하지 못해 실제 화면 조작을 종료했다. 이를 우회하거나 합성 결과를 실제 검증으로 표시하지 않는다. 독립된 구현·격리 검증은 계속한다.
