# 연결 성공 후 내 파일 이동 — 2026-10-28

사용자 추가 요구: 자료 폴더를 연결한 뒤 바로 내용을 볼 수 있어야 한다. 폴더 분류 작업과 별도의 작은 기능 변경이다.

| ID | 완료 조건 |
| --- | --- |
| CONNECT-NAV-001 | 설정에서 사용자가 폴더 연결/다른 폴더 선택/다시 연결을 실행하고 권한 확인 및 참조 저장이 성공한 뒤 `/files`로 client navigation. 지연 타이머 없음 |
| CONNECT-NAV-002 | 선택 취소·권한 거절·저장 실패·중복 요청·오래된 요청 결과는 이동하지 않음. 기존 연결이 connected여도 이번 요청 실패를 성공으로 추측하지 않음 |
| CONNECT-NAV-003 | `/files`에서 성공한 연결은 같은 URL로 다시 push하지 않음. 연결 해제는 이동 대상 아님 |
| CONNECT-NAV-004 | 사용자가 대기 중 다른 화면으로 떠나면 늦은 완료가 사용자를 `/files`로 끌어오지 않음. 단순 연결 상태 복원/설정 재방문도 이동하지 않음 |
| CONNECT-NAV-005 | controller는 이번 작업의 성공 여부만 반환하고 라우터를 모름. UI가 라우팅을 소유. picker/requestPermission은 원래 클릭 활성화 흐름 안에서 즉시 호출 |

검증: 실제 controller/session 테스트에 성공·실패·취소·오래된 결과 반환 계약 추가 → red 확인 → 구현. 격리 브라우저에서 설정→연결→실제 목록, 실패 유지, 떠난 화면 유지, 재연결을 검사한다. OPFS/합성 권한 경계이며 네이티브 OS 선택창 인증이 아니다.
