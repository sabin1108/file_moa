# 파일 작업 후속 계약 — 2026-11-03

요구사항26~33. 사이트 열기 요청은 요구사항에 포함하지 않는다. 선택 UX는 사용자가 ‘마지막 체크 해제 시 자동 종료 + 전체 선택 해제 유지’로 확정했다.

- FLOW-001: 계획의 출발→도착 표시를 짧게 순차 등장시킨다. 공간은 미리 확보하고 전체 dialog/목록은 움직이지 않는다. 동일 계획의 무관한 렌더에는 재생하지 않는다. reduced-motion에서는 즉시 모두 표시한다.
- FLOW-002: 실제 검사 전체 성공 이후에만 파일 내용→변경 여부→이름 충돌의 체크를 순차 공개한다. 검사 중은 로딩, 실패/취소는 성공 체크0. 순차 공개는 표시 효과이며 실제 검사 단계 진행률이 아니다. 실행 권한은 기존 실제 결과로 판단한다.
- SEARCH-013: 현재 폴더 아래 이름 검색. 파일/폴더의 전체 상대 경로로 식별하고 결과 아래 발견 위치를 표시한다. 본문 읽기/쓰기/권한 요청0. 명시적 검색어 입력 때만 스캔한다.
- SEARCH-014: 최대20,000항목·1,000폴더·깊이64·결과1,000. 각 폴더를 읽기 전15초 예산을 확인하며 브라우저 I/O 자체를 강제 종료하는 timeout은 아니다. 한도/일부 폴더 실패는 일부 검색임을 명시한다. 권한 상실은 전체 중단. 검색어/폴더/연결 변경·닫기/취소 시 이전 결과 폐기. IME 조합 중에는 새 검색어를 확정하지 않는다. 새 결과를 현재 목록의 다중 선택으로 잘못 합치지 않는다.
- SELECT-024: 상시 선택 버튼 제거. 길게 누르기/포커스된 항목의 Space로 선택 진입. 마지막 체크 해제와 전체 선택 해제는 모드 종료. 종료 때 사라진 checkbox 초점을 동일 항목으로 복귀한다.
- SELECT-025: 이전 확인 열에도 파일/폴더를 표시하며 길게 누르면 해당 부모를 재조회한 뒤 같은 이름·종류가 남아 있을 때만 선택한다. 늦은 요청/연결 교체/삭제/종류 변경이면 선택하지 않는다. 다른 위치 선택을 섞지 않는다.
- PATH-018: 슬래시/역슬래시 상대 경로와 따옴표로 감싼 Windows 전체 경로를 해석한다. 절대 경로는 연결 루트 이름이 정확히 한 번 포함될 때만 상대 후보를 제시하고 ‘연결 폴더 기준으로 열기’로 확인한다. 접두 드라이브/부모의 동일성을 검증했다고 표시하지 않는다. 루트 불일치/중복/UNC/..은 거부, 원문 저장0.
- HISTORY-009: 복사/이동/생성 분류 버튼, 한 줄 요약→클릭/Enter 상세. 원래 관측·미확인·현재 상태 검사 의미 유지. 이동 실행은 미구현이므로 이동 분류는 명시적 빈 상태이며 가짜 기록을 만들지 않는다.
