# 데모 파일 작업 — 2026-11-18

정식 모델은 Luna, 데모 AI는 Astra 설정을 유지한다. 이 변경은 모델이나 서버 제공 자료 계약을 바꾸지 않는다.

- DFILE-001: 공개 예시 카탈로그와 현재 정리 위치로 탭의 파일 체험을 시작한다. 생성·편집·복사·이동·휴지통·복구는 이 탭의 예시 사본에만 적용한다. 개인 폴더·운영 DB·서버 자산을 변경하지 않는다. 파일 체험과 서버 원문 AI의 경계를 화면에서 알린다.
- DFILE-002: 기존 파일 목록·다중 선택·새 항목 폼·관리 작업 dialog·목적지 탐색·새 폴더·계획 검토·복구 화면을 재사용한다. 폴더 작업은 하위 파일과 빈 폴더를 포함한다. 경로 탈출·예약 이름·동일 이름·자기 하위로의 복사/이동·복구 덮어쓰기를 거부한다.
- DFILE-003: 실행 전에 계획을 검토하고 명시적으로 실행한다. 계획 후 파일 상태가 바뀌거나 세션이 만료되면 실행하지 않는다. 취소는 파일 상태를 바꾸지 않는다. 편집·이동·휴지통은 변경 전 예시를 보관하며 복구는 새 위치에 만들고 보존본은 유지한다.
- DFILE-004: 같은 샘플 세션의 sessionStorage에 파일 체험 상태와 보존본을 보관하고 새로고침에서 복원한다. 잘못된 경로·중복 ID·알 수 없는 서버 자산·한도 초과 상태는 거부한다. 저장 실패는 메모리 변경과 새로고침 손실 가능성을 알린다. 새 세션에는 이관하지 않는다.
- DFILE-005: 편집·새 파일은 서버 제공 카탈로그의 원문을 대체하지 않는다. AI 질문·정리에는 기존 제공 원문을 사용하고, 파일 체험에는 편집한 예시를 표시한다. 정식 계정의 로컬 폴더 연결과 혼합하지 않는다.

테스트는 공개 예시 중 작은 고정 카탈로그로 생성/편집/복사/폴더 이동/휴지통/복구, 충돌·취소·오래된 계획·만료·복원·저장 실패를 검증한다. 브라우저에서는 실제 공통 화면의 키보드·390/768/1440/1920px을 확인한다. 물리 IME·실제 디스크·운영 인증 성공은 별도다.
