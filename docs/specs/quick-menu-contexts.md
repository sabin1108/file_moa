# 퀵메뉴의 공통 동작 범위

요구: 작업 화면의 일반 글·미리보기·앱 내부 선택창에서도 마우스 왼쪽 길게 누르기로 기존 퀵메뉴를 연다. 화면별 등록 목록을 만들지 않는다.

- 기존 작업 화면 표시를 공통 활성 경계로 사용한다. 공개 로그인·시안 소개 화면은 제외한다.
- 이벤트 위임으로 일반 글과 빈 영역을 허용한다. 입력·버튼·링크·드래그·파일 선택의 자체 길게 누르기와 텍스트 선택은 유지한다.
- 활성 모달이 있으면 메뉴 DOM을 그 안에 붙인다. Popover의 최상위 표시를 사용해 부모의 잘림과 변형을 피한다.
- 실행 중인 파일 작업, 저장하지 않은 편집, 화면 이동 중에는 메뉴로 이동하지 않는다. 이 상태가 누르는 도중 생겨도 다시 검사한다.
- 모달 닫힘·경로 변경·중지 시 예약과 열린 메뉴를 정리한다. Esc는 메뉴만 먼저 닫는다.
- 운영체제가 여는 파일·폴더 선택창은 앱 DOM이 아니므로 대상에서 제외한다.

검증: 변경 전 일반 글·모달 재현 실패를 기록하고, 변경 후 같은 실제 브라우저 검사와 기존 퀵메뉴 검사를 실행한다. 입력·파일 선택·텍스트 선택·이동 취소·모달 종료·좁은 화면·키보드를 함께 확인한다. 실제 Windows 권한창 검증과 구분한다.
