# 작업 기록이 있는 폴더의 이동·휴지통·복구

실제 Windows 확인에서 앱이 만든 `.moa-history` 때문에 일반 폴더 전체 처리가 막혔다. 기존 보호 검사를 삭제하지 않고, 선택한 일반 폴더의 하위 작업 기록을 같은 트리 보존에 포함한다.

- `.moa-history` 자체를 직접 선택하거나 목적지로 지정하는 행위는 계속 차단한다.
- 이동·휴지통은 선택한 일반 폴더 아래 `.moa-history`의 파일도 실제 바이트·해시·핸들·크기·변경 시각으로 검사해 보관한다. 기존 수량/깊이/바이트 한도를 함께 적용한다.
- 보관·재검사·목적지 검증 후에만 잎부터 비재귀 삭제한다. 기록이 바뀌거나 보관이 실패하면 원본을 제거하지 않는다.
- 복구는 동일한 보관본에서 작업 기록까지 복원한다. 복구의 새 루트 이름은 기존 충돌 규칙을 따른다.
- 실제 복구 보관함의 표식과 다른 `.moa-*` 관리 영역은 계속 보호한다. AI 후보·일반 탐색에서 작업 기록을 공개하지 않는다.
- 일반 복사는 기존처럼 내부 작업 기록을 제외한다. 복사와 보관/복구의 목적을 구분한다.
- 예전 위치와 다른 곳으로 이동/복원한 기록은 그 예전 위치에 대한 완료 교차 검사가 확인 필요로 표시될 수 있다. 원본 기록과 보존 바이트를 수정하여 완료로 꾸미지 않는다.

회귀 검증: 기존 차단을 재현한 실패 테스트 → 이동/휴지통 보존·정확한 복구, 변경·보관 실패·보관함·다른 관리 영역 거부. 실제 브라우저 OPFS와 Windows 사용자 재확인은 구분한다.
