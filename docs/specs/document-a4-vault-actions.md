# 보관함 연결 단순화·A4 문서·일시 알림 위치

2026-11-04 사용자 후속73~76. 실제 파일 접근·원본 보존·승인 계약은 유지한다.

1. 기존 보관함 선택과 저장 핸들 권한 재확인을 별도 버튼으로 보여 혼동시키지 않는다. 기존 보관함을 선택하는 연결 버튼 하나로 정리한다. 연결된 상태에서는 ‘다른 보관함 선택’으로 표시한다. 다시 선택한 보관함의 위치·식별·권한 검사는 기존 경로를 사용한다.
2. 읽기/편집의 같은 문서 지면을690px에서 CSS210mm(약794px)까지 넓힌다. 짧은 문서의 최소 높이는 사용 가능한 폭의297/210 비율을 따른다. 좁은 화면은 줄이고 긴 문서는 늘어난다. PDF 생성·페이지 나누기·물리 모니터 실측 기능은 아니다.
3. 편집 닫기 경고와 계속/버림 버튼 사이에12px을 두고 같은 문서 폭 안에 묶는다. 사용자 결정이 필요한 이 경고는 편집기에 유지한다.
4. 일시 안내는 문서 위의 흐름에서 빼고 우측 하단 fixed 알림으로 표시한다. 폭은 최대420px, 데스크톱 우/하단24px, 작은 화면16px과 안전 영역을 사용한다. 닫기·5초 수명·읽는 동안 pause를 유지하며 중요한 오류는 자동 삭제하지 않는다.

## 검증 조건

- 권한 상실 상태에서 연결 버튼이 중복되지 않고 같은 보관함을 다시 선택해 현재 연결을 회복한다. 보관함을 새로 만들거나 본문을 쓰지 않는다.
-390/768/1440/1920/2560/3840px에서 읽기/편집 지면 폭·최소 높이가 같고 짧은 내용은 A4 비율이다.
- 저장하지 않은 경고의 버튼 간격과 폭, 우측 하단 알림 rect/fixed 위치, 문서 상단 비이동, 닫기와5초 수명을 확인한다.
- 관련 동작·타입/lint/경계/build, 최종 브라우저와 경로별 성능을 확인한다. 결과는 docs/verification/document-a4-vault-actions/README.md를 따른다.
