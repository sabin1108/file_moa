# 현재 폴더 이름 검색 — 2026-10-29

사용자 요청: 로그인은 별도 요청 때 구현한다. 그 전에는 작은 기능이 기존 기능에 연결되며 커지도록 진행한다. 이번 단위는 연결→탐색→검색→선택→미리보기/계획 검토다. Gothic A1은 별도 글꼴 검토 후보이며 검색 구현과 전역 폰트 교체를 묶지 않는다.

## 수용 계약

후속 UI 계약: [파일 우선 화면 VIEW-001~003](file-browser-navigation.md). 기본 검색 도구는 접혀 있으며 검색 닫기는 검색어를 지운다. 조합 밖 Escape는 검색어가 있으면 지우고, 이미 비었으면 도구를 닫아 검색 버튼으로 초점을 돌린다. NAV-001~004에 따른 브라우저 뒤로/앞으로 복원은 이전 방문의 검색/선택을 되살린다.

- SEARCH-001: 현재 읽어 둔 직접 자식의 파일·폴더 이름을 부분 문자열로 필터링한다. 대소문자와 NFC 정규화 차이는 무시하고 검색어 앞뒤 공백은 제거한다. 정규식·초성·본문·재귀 전체 검색은 아니다. 원래 목록 순서와 원본 이름은 유지한다.
- SEARCH-002: 입력은 목록 store가 소유해 미리보기와 같은 Provider 내 화면 왕복에 유지한다. 같은 폴더 갱신/재연결에도 보존하고, 다른 폴더 이동 시도·연결 교체·해제·소유자 변경에는 초기화한다. 이동 실패 후에도 이전 검색을 새 폴더 검색으로 오인시키지 않는다.
- SEARCH-003: 검색은 파일 읽기·권한 요청·저장·업로드를 추가하지 않는다. 최대1,000개 확인 목록 안에서만 검색하며 일부 목록 안내를 유지한다. 0개 결과는 ‘일치하는 이름 없음’이며 실제 빈 폴더와 구분한다. 오래된 목록은 그 사실을 표시하고 선택·계획은 기존 규칙으로 차단한다.
- SEARCH-004: 검색으로 숨겨진 기존 선택을 유지한다. 전체 선택 checkbox는 **현재 검색 결과의 파일만** 추가/해제하며 숨겨진 선택에 영향을 주지 않는다. 전체 선택 해제 버튼은 기존처럼 모든 선택을 비운다. 총 선택과 ‘검색 밖 N개 포함’을 표시하고 계획 검토에는 모든 선택 파일이 포함됨을 드러낸다.
- SEARCH-005: 한글 조합 중에는 입력 중 텍스트만 바꾸고 조합 완료 때 필터를 반영한다. Enter로 미리보기·계획 생성·폼 제출을 하지 않는다. 조합 중 Escape는 IME에 맡기고, 조합 밖 Escape/검색 지우기는 검색만 비우며 입력 초점을 유지한다. 검색어 확정 후 결과 수를 정중한 live region으로 알린다.
- SEARCH-006: 검색으로 보이는 파일의 미리보기에서 돌아오면 검색어·선택·파일 버튼 초점을 보존한다. 검색어 변경도 목록 상태 변경이므로 열린 변경 계획은 기존 수명 규칙에 따라 폐기한다. 검색 결과의 폴더 탐색은 기존 목록 열기를 재사용한다.

## 구조와 검증

`lib/file-name-search.ts`는 순수 이름 필터, listing store는 검색어/선택 수명, `FileNameSearch`는 조합 중 임시 입력과 키보드, `FolderListingView`는 표시 결과를 조합한다. 별도 검색 API·복제된 목록·전역 검색 저장소·새 의존성을 만들지 않는다.

고정 합성 core로 이름/유니코드/정규식 문자/폴더·파일·선택 범위·경로/갱신/취소/권한/연결 변경을 먼저 실패→통과로 검증한다. 브라우저는 실제 UI/store/session/OPFS와 합성 picker를 사용해 검색→선택→미리보기→계획의 연결, 조합 이벤트, 키보드,390/768/1440/1920px와100/1,000/1,001개를 확인한다. 검색만 수행한 구간의 본문 읽기/열거/원본 쓰기/권한 요청 증가0을 확인한다. 실제 OS IME·권한과 합성 검증을 구분한다.

기준선은 직전 기능 최종 production의 동일 코드/브라우저 측정(verification/file-change-plan/performance-after*.json, selection-after/checks.json)을 보존해 재사용한다. 변경 뒤6경로×3회×2폭과 신규 검색 비용을 측정한다. pnpm check와 관련 브라우저 회귀·화면 검토를 완료하고 다음 단위는 로드맵에 정리한다.
