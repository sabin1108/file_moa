사용자 ‘일단 5번까지는 해보자’ 승인 범위: 통합 채팅 실사용, 실제 AI 지연/사용량, Windows 실제 환경, 과거 근거 링크 복원, 대용량/접근성이다. 배포·새 의존성·제한 제거·로컬 AI/위키/성장은 포함하지 않는다. 기존10회·전송 동의·원본 보호·owner 격리를 유지한다.

1. 실제 제품 UI와 합성 파일로 일반→검색→정리→일반/저장/재열기 경로를 검사한다. 실제 AI는 비개인 합성 요청으로 최대2회 생성, 자동 재시도 없음. 실제 계정 세션을 만들거나 운영 DB 사용자/자료를 변경하지 않는다.
2. 기존 임시 PostgreSQL harness를 재사용해 실제 공급자→SSE→사용량 완료를 검증한다. 운영 DB는 SELECT-only 왕복 진단만 한다. 격리 DB/직접 handler와 실제 인증 배포 경로의 차이를 기록하고 실제 비용/속도 개선으로 과장하지 않는다.
3. OS 권한창·물리 한글 입력과 합성 거부/철회/외부 변경 검사를 구분한다. 자동화가 보안 권한을 대신 승인하지 않으며 가능한 실패 경로와 실제 파일/Worker 검증을 먼저 끝낸다. 물리 확인은 별도 남긴다.
4. 저장 대화에 owner·connection ID·상대 경로·크기/해시·인용문만 보존한다. 원본/전체 발췌/핸들/전송 동의는 복사하지 않는다. 복원한 링크는 클릭할 때 동일 연결·권한과 실제 읽은 바이트/인용을 다시 검사한다. 같은 경로의 다른 파일/다른 폴더를 묵시적으로 연결하지 않는다. 공통 원문 미리보기와 검증 Worker를 재사용한다.
5. 기존500문서/1000목록/50MiB/2MiB/PDF50쪽·텍스트 상한을 유지한다. 기존 경계 검사와 실제 PDF Worker 하네스를 재사용하고 부족한 PDF 실패/쪽수 경계 및 키보드/좁은 화면을 보완한다. 수치의 조건·데이터 크기와 테스트 개수를 구분한다.
