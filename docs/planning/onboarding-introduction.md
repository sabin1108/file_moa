# 모아 소개 페이지 — 2026-11-11

## 사용자 요구

온보딩은 가입을 강제하는 설정 단계가 아닌 기능 소개 페이지다. ego lite와 Toss의 큰 제목, 넓은 제품 지면, 스크롤에 따라 이어지는 설명을 참고한다. 체험판은 일반 소개에 노출하지 않는 공유 링크로 유지하며 체험판에도 같은 소개를 제공한다. 링크 비노출을 초대 인증이나 접근 제한으로 표현하지 않는다.

## 실제 기능과 소개 내용

- 자료 찾기: 로컬 폴더의 키워드 검색과 원문 근거를 보여 준다. 일반 자료 검색을 의미 검색이라고 표현하지 않는다.
- AI 대화: 확인한 자료를 질문에 연결하는 예시를 보여 준다. 선택한 내용의 전송 확인을 생략하지 않는다.
- 정리 계획: 파일 변경 전 목적지와 계획을 검토하고, 실제 적용은 별도 확인이 필요함을 알린다.
- 기록과 위키: 대화·결과물·출처를 기록으로 이어가는 실제 기능을 소개한다.

개인 파일이나 운영 모델을 불러오지 않는 소개 예시로 제품 장면을 구성한다. 사용자 수·성능·고객 평가를 만들지 않는다.

## 디자인 결정

기존 은회색·네이비와 시스템 글꼴을 유지한다. design-taste의 Colour chapters 방향(seed 831972569)에서 기능마다 달라지는 바탕과 큰 제품 장면을 채택한다. 참고 사이트에 맞춰 첫 화면은 짧은 중앙 제목과 펼쳐지는 자료 장면, 이후 화면은 설명과 구체적인 자료 표시를 번갈아 배치한다. 실제 제품 표시 조각은 data-ui로 구별하며 원래 앱의 조작 크기와 계층을 참고한다.

이 페이지에서 흩어진 로컬 문서는 하나의 폴더와 읽기 지면으로 모인다. 자료 예시 선택은 네이티브 라디오로 제공해 키보드와 터치로 확인한다. 스크롤 효과는 CSS로 점진 적용하고 움직임 감소 설정에서는 읽기와 조작을 그대로 유지한다.

사용자 추가 요청에 따라 `jakubkrehel/skills`의 better-ui, better-typography, better-writing을 작업 폴더로 받아 적용했다. 기존 팔레트와 글꼴을 유지하고 150ms 조작 반응·누름 비율 0.96·움직임 감소·내용이 사라지지 않는 초기 표시·짧고 구체적인 버튼 이름·단위 없는 행간과 한글 줄바꿈을 검토한다. 공통 인터페이스 전체를 검토한 것으로 확대하지 않는다.

## 연결 범위

- 공개 소개: `/start`. 일반 로그인·가입으로 연결하고 체험 링크를 포함하지 않는다.
- 공유용 체험 소개: `/demo/intro`. 같은 표시 컴포넌트를 재사용하고 체험 시작으로 연결한다. 검색 결과 제외 메타데이터를 설정한다.
- 기존 `/demo/start`는 소개를 먼저 보여 주며, 소개의 명시적 시작 링크에서 기존 세션 생성으로 진행한다. files 진입 의도와 유효한 샘플 세션은 보존한다.
- 기존 작업 경로와 인증·자료 접근 계약은 유지한다. 제품 전체 폴더 이동이나 시안 삭제는 하지 않는다.

## 검증

소개 전 샘플 세션 미생성, 시작 후 샘플 세션만 생성, 기존 인증 쿠키 보존, files 목적지 유지, 설정 누락 실패를 기존 테스트에 추가한다. 전체 테스트·타입·린트·빌드와 구조 검사를 실행한다. ego-browser로 참고 사이트와 결과를 확인하며 1440/1920px, 768px, 390px, 키보드·움직임 감소·공개/체험 CTA를 검증한다. 유료 AI 호출이나 실제 파일 권한 요청은 하지 않는다.
