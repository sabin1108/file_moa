# 전체 완성을 위한 남은 작업

## 최신 사용자 범위 — 2026-11-10

직전 사용자 목록1~7의 검증과15 OCR·18 출처 연결 위키를 진행한다. OCR은 승인한 한국어·영어 엔진을 같은 사이트에서 제공하고, 위키는 기존 자료 답변과 기록 저장 계약을 재사용한다.16은 AI 대화의 의미 이해만 유지하며 실제 검색은 키워드 방식이다.17 로컬 AI·20 Kakao는 이번 범위에서 제외한다.8~14와19·21·22는 보류한다. 아래 과거 표의 번호와 혼동하지 않는다.

구현과 격리 브라우저 검증은 [OCR·위키 보고서](../verification/ocr-wiki/README.md)를 따른다. 실제 로그인 완료는 사용자 보고이며, Windows 권한·물리 한글 입력·실계정 소셜 복귀·외부 변경과 전체 실제 여정은 직접 관찰하지 못했다. 현재1~7 전체를 완료로 표시하지 않는다. 현재 사용량 제한 유지, 새 유료 생성·배포·푸시 없음.

## 현재 추적 기준 — 2026-11-09

일반 대화·자료 찾기/정리·대화 기록·결과물·프로필/승인 기억·다중 원본 폴더·PDF/로컬 색인·사용량 원장·계정 수명은 제품에 연결돼 있다. [1~9 추적](workspace-nine.md)과 [1~5 후속 검증](../verification/first-five/README.md), [현재 UX](../verification/workspace-ux-rebuild/README.md)를 따른다. 아래11월8일 표의 ‘미구현/후속’은 당시 기록이다.

사용자는 이어갈 우선순위로 **현재 기능 검증·배포 준비**를 선택했다. 이번에는 [브라우저 경계 개선 계획](browser-boundary-improvement.md)에 따라 내부 전역 이벤트·초안/설정 저장·기록 저장소 주입을 개선하고, 현재 소스의 회귀·인증·비밀 검사·빌드/원격 기준점을 확인한다. 실제 푸시나 배포는 이 우선순위 선택만으로 실행하지 않는다.

남은 실물 확인은 실제 Windows 권한·물리 한글 IME·실계정 소셜 복귀·사용자 전체 경로의 속도/장기 부하다. OCR/의미 검색·로컬 AI·위키/성장은 별도 후속 기능이다. 이미 구현된 기능을 다음 기능처럼 다시 추가하지 않는다.

## 이전 추적 기록

2026-11-09 최신 UI 기준: 사용자 확정에 따라 일반 대화·자료 찾기·정리를 단일 대화/입력으로 통합했다. 요청 자동 판별·애매한 경우 확인, 역할별 UI 재사용과 전송 동의를 유지했다. [현재 통합 검증](../verification/unified-conversation/README.md)을 이전 모드 분리 설명보다 우선한다. 전체 제품·실모델/물리 검증·배포 완료를 뜻하지 않는다.

2026-11-09 후속: 아래 11월8일 표는 당시 목록이다. 직전 별도1~9의 현재 상태는 [갱신한 추적표](workspace-nine.md)를 따른다. [후속 검증](../verification/follow-through/README.md)에서 정산·자료 인용·S0 경로를 보완하고 100/500개 대화와 DB 왕복을 측정했다. 실제 Windows 권한/물리 IME·실모델 속도/정산·인증 field 성능·배포는 남아 있다.

최신 갱신 2026-11-09: 사용자는 직전 별도 목록1~9 구현을 승인했다. [현재 실행 추적](workspace-nine.md)과 [검증 결과](../verification/workspace-nine/README.md)를 아래11월8일 상태보다 우선한다. 대화 기록·자료 질문·결과물·승인 기억·다중 폴더·PDF/색인·계정 삭제가 제품에 연결되었다. 사용량 원장은 설명 뒤 승인에 따라 실제 DB 적용과 로컬 활성화를 완료했으며, 실모델 속도·물리 Windows·의미 검색/OCR·후속 전체 기능은 미완료다. 최종 AI 횟수 제한 제거는 후속 방향이고 현재 제한은 유지한다.

기준일: 2026-11-08. 사용자는 처음 구상한 기능 전체를 최종 완성 범위로 유지하고, 오늘은 아래 1~5번을 구현·점검한 뒤 인수인계·커밋·푸시하도록 요청했다. 이 문서는 계획이며 통과 증거가 아니다. 현재 구현은 실제 파일 탐색·보존·정리와 인증 기반이 앞서 있고, 자료 없는 일반 AI 대화는 아직 완성되지 않았다.

1~6만 끝났다는 이유로 전체 제품 완성을 선언하지 않는다. 초기 두 축 완성은 7~9까지 필요하고, 전체 완성은 사용자가 정한 후속 범위까지 따로 추적한다. 남은 기간은 일반 채팅·기록·자료 대화의 상세 범위와 실제 검증 결과를 확인한 뒤 산정한다.

사용자 조작은 실제 소셜 인증·운영체제 권한창·물리 키보드·기존 개인 브라우저의 결과 확인에 한정한다. 개발·모의 테스트·소스 점검·정리·기록은 작업자가 진행한다. API 크레딧과 실제 결제액은 대시보드 기준이며 추정 토큰 비용을 결제 실측이라고 부르지 않는다.

11월8일 결과와 미검증 범위: [점검 기록](../verification/completion-five/README.md). 11월9일 일반 채팅(7)은 사용자의 실시간 스트림 선택에 따라 제품 경로에 연결했다. 이후 사용자는 이메일·소셜 로그인과 일반 채팅 송수신 성공을 확인했다. [표시·지연 개선](../verification/chat-smoothness/README.md)의 자동 검증은 모의 모델이며 수정 뒤 실모델 속도/배포 전체 여정과 구분한다. 로그인 속도는 사용자 지시로 최하 순위다. 마지막 Windows 단계 확인·권한 철회·외부 변경은 별도 남아 있으며, 대화 기록(8)과 자료 근거 대화(9)를 이번 완료로 표시하지 않는다.
