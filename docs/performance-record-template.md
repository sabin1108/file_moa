절대 차이 = 이후 − 이전. 상대 변화율 = (이후 − 이전) / 이전 × 100. 이전이 0이면 변화율은 계산하지 않는다.
작은 lab 반복은 중앙값과 범위, 충분한 반복 작업/부하는 p50/p95 및 n을 적는다. 서로 다른 도구의 비슷한 이름 지표를 합치지 않는다.
CPU나 메모리 감소만으로 사용자 체감 향상을 주장하지 않고 작업 완료 시간도 확인한다.
